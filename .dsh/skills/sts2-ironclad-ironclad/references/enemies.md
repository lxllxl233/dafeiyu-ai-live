# 敌人速查 v3 · 按幕/遭遇（不是字母表）

> 开战前：按幕找到这场遭遇，读「先做什么」。战斗内一律以 `state` 的 `MECHANICS`/`ANCHOR` 为准。
> HP 为 db 基础值；标了 A10 的用实测值，其余 A10 约 +5~10%，以实时血条为准。
> 记号：🔥 可能直接带走一局｜⚠️ 会滚雪球｜— 按流程打。

## 七条通用原则

1. **召唤者**：本体 2 回合内能杀 → 直杀本体；本体厚（>4 回合输出）且爪牙贡献 ≥40% 入伤 → 先清爪牙。
2. **荆棘/反伤**：先算每段反伤，多段硬打=自杀；先叠格挡再攻击。
3. **Buff 回合不是安全回合**：按「下一击」留血线。
4. **多段 N×M**：挡牌按总值；每段独立吃格挡/胆小/荆棘。
5. **成长型先杀**：仪式/领地/力量成长，越拖越疼。
6. **眩晕窗口**（骇鳗/地道虫/碗虫石/仪式兽）要提前算，不是碰运气。
7. **会复活/接续**（实验体/千足虫/外骨骼/巨斧）要留收尾，别把爆发打在第一条命上。
