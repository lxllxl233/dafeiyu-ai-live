# 铁甲战士 A10 · 手册（按需读，不常驻）

> `SKILL.md` 只留每回合要用的核；这一份放"一局看几次"的细节。**只读当前需要的那一节。**

## 1. 路线（开局 / REPLAN 时读）

- **commit 前扫下游**：找「唯一出口是精英」的节点（44 局 8 层四园丁），低血降权。
- **REPLAN 触发**：血线 <70%｜本段掉血 ≥20% 最大｜拿到首张 AOE｜金币 100+｜牌组 +3｜多诅咒。
- **低血优先级**：营火 > 问号 > 商店 > 普通怪 > 精英；同分选营火多且位置靠前的线。
- **血量经济**：5–10 血换小怪可、15–25 血换精英可、30+ 是警报。
- **商店顺序**：药水 > 删牌 > 遗物 > 卡；100+ 金就规划，Boss 前把钱花光（≤20）。
- **营火**：<50% 必睡；≥70% 必锻；50–70% 看下一格（下一格是怪就睡）。

## 2. 构筑细节（奖励 / 商店 / 删牌时读）

| 指标 | 目标 | 红线 |
|---|---|---|
| 张数 | Act1 12–15，最终 16–18 | >18 只拿质变 |
| 打击 | Act1 ≤4，Act2 前 ≤3 | 5 张进 Act2 = 稀释 |
| 防御 | 进 Act2 ≥6，其中 2 张 8+ | 单回合最大格挡 < 精英入伤 = 必输 |
| AOE | 1–2 张 | 0 AOE = 多怪被磨死（42/44 局） |
| 收尾 | 1 张（重锤/余烬/完美打击/全身撞击/恶魔之焰） | 无收尾 = 打不死 Boss |
| 运转 | Act2 前 4 运转 + 2 回费 | 只有一套启动 = 死 |

- **抓牌**：只补缺口；牌组 ≥14 只拿 A 级，≥16 只拿质变；**`skip_reward_cards` 也会加卡**。
- **按缺口抓**：AOE 第一优先（0 AOE 时 AOE > 任何单卡）> 主轴核心（腐化/主宰/黑暗之拥/无惧疼痛）> 防御（岿然/火焰屏障/巨像/耸肩/坚毅）> 运转（燃烧契约/剑柄/战斗专注/祭品/放血）> 收尾（完美打击/全身撞击/重锤）。
- **循环解（剑耸）**：2 抽牌（剑柄/耸肩/劫掠/怨恨/契约）+ 1 加费（放血/仪式）互抽；战士缺抽不缺费。
- **主轴二选一**：消耗流（腐化+黑暗之拥+无惧疼痛+契约终结）｜主宰易伤流（主宰+凶恶+残酷+欺凌+痛击/挑衅/上勾拳）。
- **升级优先级**：痛击 8→10（+1 易伤）｜耸肩 8→11｜坚毅 7→9（随机→定向）｜剑柄 9→10 抽 2｜全身撞击 1→0 费。
- **删牌**：先买卡/遗物，钱没处花再删；重振/地狱狂徒先来删打，狂怒/劫掠先来删防。
- **整局目标**：Act1 结束 HP≥70%、12–15 张、1–2 AOE、1 张收尾；Act2 15–18 张、4 运转 2 回费、基础牌 ≤3。

## 3. 敌人（进战前查 enemies.md 对应行）

- **召唤者**：本体 2 回合内能杀 → 直杀本体，否则先清爪牙（本体死爪牙撤退）。
- **荆棘/反伤**：先叠格挡再多段；多段硬打=自杀。
- **成长型**（仪式/力量/领地意识）：先杀或先破。
- **Buff 回合不是安全回合**：按下一击留血线。
- **胆小/滑溜/无实体**：用 AOE/多段破；多怪精英没 AOE 不进。
- **A1 Boss 时序**：瀑布巨兽 Buff→…→**Stun（白给，别交甲）**→**DeathBlow 44**（应急按钮留到这一回合；30<44 需 HP≥14）｜仪式兽 150 晕 + Ringing｜神官先杀本体｜墨影 滑溜 9 用多段｜异鱼 无实体 2 + 呼唤必打｜族母 睡 3 回合。

### 3.1 AOE 清算表（多怪时先算这张）

| 牌 | 费 | 对 N 只总伤 | 每能量（N=3） | 备注 |
|---|---:|---:|---:|---|
| 突破 Breakthrough | 1 | 9N | 27 | 自伤 1，触发狱火/狂怒类 |
| 旋风斩 Whirlwind | X | 5X·N | 15X | 能量越满越强，清场首选 |
| 万向斩 Omnislice | 0 | 8N | ∞（0 费） | 0 费 AOE，必打 |
| 闪电霹雳 Thunderclap | 1 | 4N | 12 | 附全体易伤 1 |
| 契约终结 Pact's End | 0 | 17N | ∞（0 费） | 需消耗堆 ≥3 |
| 飞剑/拆卸 | 1 | 8–14（单体） | — | 多段≠AOE，别算错 |

**判定顺序**：① N=1 → AOE 按单体算，不用；② 算 A = 本回合 AOE 总量、H = 全场血：A ≥ H = **清场回合**，先上易伤/降费再一发收；③ A < H → 算「打完每只残血」，能量优先收掉会杀人的那 1–2 只；④ 召唤型敌人（N 从 1 变 4–5）→ 召唤前把 AOE + 能量留好。

## 4. 精英 / Boss 总账（进战前算一次）

```
T ≈ 敌血 ÷ 我的实际 DPS（含力量/易伤）
N ≈ 敌入伤 − 我能稳定挡下的
T × N > 当前血量 × 0.6 → 不打
```

- **Act1 Boss DPS 闸**：199 血祭司 / 262 血仪式兽 ÷ 15–18 伤 = 11–13 回合，而 Boss 每回合 19–33 → 必输（50 局）。不够先补收尾牌 + 2 张 8+ 格挡。
- **三闸只是必要条件**：再加「单回合格挡 ≥ 敌每回合入伤」和「HP ≥70%」。
- **Boss 前清单**：HP≥70%、2 张 8+ 防御、牌组 ≤18、金币 ≤20、药水先验过。
- **昏眩/Ringing 回合只能出 1 张**：进昏眩前 HP > Boss 最大单回合攻击。

## 5. 工具坑（报错时读）

| 坑 | 做法 |
|---|---|
| `end_turn` 快照还没抽牌 | 一律先 `state` 重读；`HAND_STALE` 是提示 |
| play_card 返回 WAIT/失败 | **绝不接 `end_turn`**：重读 state 再打同一张 |
| 工具报错 | 缺目标自动选最低血；play_card 失败重读后重试 1 次 |
| 手牌索引会变 | 每张牌后重读；单张 `play <CARD_ID>`，多张 `do play_card --card <i>` |
| 牌面与本地库不一致 | 以实时 `resolved_rules_text` 为准 |
| 多段意图 | 看 `ANCHOR` 的 `dmg=8x4=32`，按大值挡 |
| 卡牌奖励 | 只用 `choose_reward_card --option i`；`skip`/`resolve` 也会加卡，之后核对 `deck N` |
| 药水 | `--option` 是槽位；要目标时 `--target`；pending 重读看 `is_queued`，最多试 1 次 |
| 下标连打 | `--card` 前必须看到 `state` 那一行 |
| PowerShell | 不支持 `&&`；`--meme` 别用英文双引号；中文乱码写文件再读 |

## 6. 反模式全表（见到就停）

**数学**：① 多怪只看一只｜② 半挡半打｜③ 差 1–2 点没收掉｜④ 不重读按旧斩杀线打｜⑤ H′≤I′ 还在换血。
**防守**：⑥ 非斩杀回合全输出｜⑦ 有格挡牌却弃盾｜⑧ 对荆棘/高甲硬砍｜⑨ 预斩杀不叠盾｜㉔ 入伤 7–10 用"抢节奏"硬吃｜㉕ 药水带满不喝。
**构筑**：⑩ 奖励全拿、18+ 张｜⑪ 有移除机会却删错｜⑫ 营火升打击/防御｜⑬ 三条轴混抓。
**决策**：⑭ 进精英/Boss 不算总账｜⑮ 药水等血见底｜⑯ 凭记忆点下标｜⑰ 低血选出口是精英｜㉑ 低血接战 / 0 AOE 进多怪精英｜㉒ 只看分数不看下游。
**操作**：⑱ 有费空过｜⑲ 开场白谈上局｜⑳ 梗刷屏或哑火｜㉓ play 失败直接 end_turn｜㉖ 药水 pending 后仍按有药算｜㉗ 一条命令连打两张牌。
