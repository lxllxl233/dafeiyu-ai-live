# 铁甲战士 A10 · 决策 OS v21（结构化输入 / 结构化输出 / 药水牌序）

> 常驻只本文件；references 触发时 `read`，别整份读。

## 0. 传输协议：一回合 = 1 次 `ctx` + 1 次 `act`

```powershell
python tools/ctx.py                       # 只在进战斗/换界面/auto 停/拿不准时读一次
python tools/act.py --file tmp_plan.json  # 执行 seq，回下一回合 ctx（下一回合直接用它）
```

- **一回合 1 次请求**：`act` 返回的 `ctx` 就是下回合局面包，直接决策再 `act`。

```json
{"say":["它 16，痛击加一刀刚好带走。","另一只吃尸体，这回合没人打我。"],
 "seq":[{"c":"BASH","t":0},{"c":"STRIKE_IRONCLAD","t":0},{"end":1}],
 "fx":{"e":1,"hp":59}}
```

- `c`：`card_id`（不写下标；升级版写 `STRIKE_IRONCLAD+`；同名多张默认打最便宜/最强那张）。
- `t`：敌人下标；可省（默认打威胁最大的活怪）。`p`：药水槽，targeted 必须给 `t`。
- `end`：最后一步。**不写 `end` = 只打到一半就停**，回 `mid:1`；抽牌后读 ctx。
- `say`：1–3 句；第一句随本回合播，其余排队；写法看 `sts2-caster`。
- `fx`：可选自报账；写 `e`/`hp`/`take` 会被硬校验，和本地账本不一致就**整手不打**打回。
- **省请求**：杂怪（非精英/Boss、血安全）加 `{"auto":{"turns":3,"stop_hp":40}}`，本地连打，血线到/战斗结束/进选牌就停。一场杂怪 1 次请求。
- `{"ok":false,"err":...}`：一张没打（或打一半 STOP）。用返回的 `ctx` 改 `seq` 重发，**绝不**自己补 `end_turn`。
- **护栏（`act` 硬拦，run69 血债换的）**：①`护栏·漏斩` 有能校验通过的全斩线却没斩；②`护栏·漏费` 结束回合还剩能量且手上还有牌能打；③`护栏·漏甲` 这一手要净挨 ≥6 点、起手有 ≥4 甲的防御牌却没打。被拦时按 err 里的提示改 `seq`；确认要换血/留费，在 plan 顶层写 `{"allow_take":1}` / `{"allow_leftover":1}` / `{"allow_no_lethal":1}` 并说明理由。
- **`hand_n` = 真实手牌张数**（`hand[]` 同名牌会合并成一条，只看条数会以为牌少）。`stale_ctx` 出现 = 新回合还没抽完牌，**必须**重读 `tools/ctx.py` 再出牌。
- **遗言告警（run72 血债换的）**：敌人身上带「蒸汽喷发 / 爆炸 / 亡语」时，斩杀**不等于安全**——它死后还会按层数结算一发（瀑布巨兽实测 44 点，可被格挡/缓冲吃掉）。`act` 会在「清场且 0 甲」时给 `warn: 遗言警告`，看到就检查这一手有没有甲或缓冲药水。
- **`fx` 报错会带答案**：`fx.hp/fx.e 不对` 时 err 里直接给出实际值，照抄重发即可，别自己重算。
- **SL 不改变抽牌顺序**（run72 实测：`save_and_quit` → continue 后开局手牌完全一样）。SL 只在**操作失误**时有用，别指望刷牌序；每幕预算 ≤2 次。
- **商店每店只能删 1 张牌**（run72 实测），别把「连删 3 张」写进计划。
- **药水栏满时 `claim_reward` 会静默成功但不给药水**：拿奖励前先看 `potions` 槽位，满了先 `discard_potion`。
- **「从牌组移除 N 张」的多选界面点不动（已知 blocker，`docs/TODO_mod_deck_remove.md`）**：涅奥的「精准剪刀/松动羊毛剪」这类选项会打开 `CARD_SELECTION`，但 `max_select=0`、`select_deck_card` 只返回 `pending`、`confirm_selection` 不可用 → 卡死。**别选这类选项**；已卡住就 `save_and_quit` → `continue_run` 回滚。
- **诅咒分两种**：`进阶之灾`（虚无）每回合手牌 −1；`贪婪`（永恒）**删不掉**，商店删牌列表里不出现。别把「删诅咒」写进商店计划。
- **只堆甲会死于消耗战**（run74：13 张牌 5 张攻击 → 一回合 18 伤，被 53 血杂怪磨死）。甲牌 ≥45% 必须配「非基础高伤攻击 ≥2 张」，`python tools/gates.py` 会同时检查这两条。

## 0.5 输入：`ctx` v3 字段（每次请求都同步）

| 字段 | 内容 |
|---|---|
| `me` | hp/max/blk/e/em/stars/`buffs[]`（力量/敏捷/覆甲等跨回合 buff 在这） |
| `relics`/`potions` | 遗物 `[{i,id,n,fx,st}]`；药水 `i/id/n/d/t/use/st`+`nxt` |
| `hand` | **实费** `c` + 张数 `q` + `t` + `dmg/blk/draw/vuln/weak/aoe/x/exh/cm/add/pw/play`；`kw`=词条（EXH/ETH/UNP…）、`tx`=机制原文、`nxt`=留给下一轮 |
| `enemies` | `i/id/n/hp/max/blk/b/bd/it/nx/nx_tot/hist/mech` |
| `piles` | `draw`/`dis`/`exh`：张数 + 组成 |
| `calc` | `inc/blk/net/full/lethal/chain/aoe/tax` + `dmg/ttk/ttk_all/nx_inc/nxdraw` |
| `can`/`plans`/`warn` | 详见 `references/ctx_fields.md` |

- `mech`=DB 机制（`招：藤蔓9A+W｜挥击7A｜大啃18A`）｜`bd`=当前 buff 机制｜`it.tot` 已含力量与我方易伤。
- `calc.dmg`=本回合伤害上限，`calc.ttk`=还几回合杀，`nx_inc`=下回合预计入伤，`nxdraw`=下一手期望甲/伤。
- 意图码、`cm` 变费、`plans` 五类/`risk` → `references/ctx_fields.md`。

## 0.6 输出：牌序就是资源顺序

```
0 费/回能/抽牌/变费牌 → 易伤/力量 → 高伤攻击 → 药水补费/补刀/保命 → end
```

1. **变费**：`UNRELENTING` 后最大攻击 0 费；`STOMP` 放最后；`CORRUPTION` 技能全 0 费；`BLOODLETTING/OFFERING` 先打再付大牌。
2. **药水**：补能量在攻击前；斩杀药水最后补刀；格挡/回血在 `end` 前；targeted 写 `t`，否则 `invalid_target`。
3. **抽牌/烧牌**：`POMMEL_STRIKE/BATTLE_TRANCE/OFFERING` 先打，斩杀线别建在随机抽牌上；`POWER_THROUGH` 先算 2 张伤口税；`FEEL_NO_PAIN/DARK_EMBRACE` 烧牌前打。
4. **能量纪律**：结束 `e=0` 或写明「不可打/零收益」；0 费攻击必打；同 id 打最便宜/最强副本。
5. **铺下一轮**：`hand[].nxt`/`can.buff` 是「这回合铺、下回合收」的入口；斩杀回合不铺。

## 0.7 每回合七步

```
1 读 warn + me.hp/blk/e + potions（有药先过四问）
2 读 enemies：`mech` 先判机制（召唤/塞牌/成长/反伤/分裂）；`it.d×h`（×力量×虚弱）＝**每怪本轮入伤**，逐个加总核对 `calc.inc`；`nx` 预判下一手，`hist` 找周期
3 读 calc：inc/blk/net/full/lethal/chain/aoe/tax；算「杀→晕」与两回合账（要铺就看 `hand[].nxt`/`can.buff`）
4 定回合类型：斩杀｜全挡/喝药｜≤10% 最大生命挡满｜换血（净掉≤5）｜铺场
5 选线：kill→stun > AOE 清场 > 全挡 > 换血 > 铺场；plans 全看，`maxdmg` 的 `risk=1` 只作上限
6 写 seq（牌+药水按资源顺序），能自报就写 fx
7 收尾三查：e=0/N｜没有能打的格挡牌｜没有 0 费/回合末扣血牌
8 空费诊断：e>0 且手里只剩状态牌/不可打牌 → 不是手慢，是**牌组攻击牌 <6**；记 `deck_issue`，下个商店先补每费价值 ≥8 的牌再删牌
```

## 0.8 记忆分层

- **L1** `sts2.py memory --write`：开局/换幕/新 session/每 4–5 层。
- **L2** 每回合 `ctx.py`；下一回合用 `act.py` 返回值，不再 `state`。
- **L3** `journal --floor N --last 20` 复盘才用；`logs/run_*.jsonl`/战报不进上下文；每幕 `memory --write` 后开新会话。

## 1. 三条铁律

1. **先算死**：`calc.inc` vs `me.hp + calc.blk + 药水`；`inc ≥ hp` → 全挡/斩杀/喝药，禁半挡半打。
2. **小伤害必挡**：≤8 挡满；9–14 吃满 `calc.blk`，差额才是换血额度；≥15 全挡/斩杀/喝药。
3. **怪不打伤害就少起防**：所有 `it.t` 不含 `A`（沉睡/纯 buff/只上 debuff/塞牌）→ 0 甲全输出；`calc.inc==0` 时 `warn` 会给「可少起防」，别浪费防御牌。甲到下回合会清零，本回合多打的甲只有「本回合被打」才有价值。
4. **回合账**：`calc.dmg` 是这回合上限，`calc.ttk` 是还几回合死；`nx_inc` 是下回合预计吃多少，`ttk_all > 1 且 nx_inc ≥ hp` → 这回合优先全挡或灌伤害，不是折中。
5. **结束前三查**：`me.e=0`｜没有能打的格挡牌｜没有能打的 0 费牌、没有「回合末扣血」牌。

## 2. 准入闸

- **血闸**：<50% 只接营火/事件｜<60% 不进精英（召唤型 70%）｜<70% 不进 Boss；唯一出口是精英先把血养到 60%。
- **倒推闸**（每层都算）：`出幕血 = HP − 剩余必经战×8 + 营火×0.3×max`；到 Boss <70% → 下一节点只走营火/商店，拒精英、拒加牌。**出度 1 指向精英 = 必打**，按「到那层时的血」预判，不够就在第 1 层避开这条线。
- **多怪闸**：`can.aoe=0` 且敌 ≥3 → 不进精英。
- **换血闸**：花血换 relic/金币先答「Act1 内回得了本吗」：+1 最大生命/场最多回 5–8，不值 14 点现血。

## 3. 数值与斩杀

```
单卡伤害 = hand[].dmg（已含力量/虚弱/遗物）
修正：敌易伤 ×1.5｜我虚弱 ×0.75｜我脆弱 格挡 ×0.75｜敌格挡先扣｜胆小首击 +6/7｜荆棘每段反伤
敌减伤/封顶：振翅 ×0.5（攻击伤害减半）｜无实体 = 每段 1｜难以杀灭 = 每段封顶 9｜人工制品先吃 1 次 debuff（易伤/虚弱白给）
多段：每段独立吃格挡/胆小/荆棘（飞剑 3×3、双发 5×2 要乘段数）
AOE 清算：总量 A vs 全场血 H；A≥H 清场；A<H 收最危险 1–2 只；N=1 不用 AOE
```

- **每费价值**：飞剑+ 12｜耸肩+ 11｜飞剑 9｜余烬 9｜上勾拳 6.5｜打击 6｜防御 5。
- **状态牌**：感染 3 伤、燃烧 2 伤、剧毒 5 伤、呼唤 6 伤（无视格挡）全算进 `calc.tax`；可格挡部分与 `incoming` 共用格挡池；黏液 1 费抽 1，Wound 无回合末伤害。
- **自伤四问**（放血/祭品/血墙/突破）：2–6 血换的能量本回合能斩杀/挡 ≥ 自伤吗？HP ≤40% 不交；有别的回能不交。
- 跨费先看 `plans[].d` 与 `calc.lethal`，别用旧斩杀线。

## 4. 多怪 / 机制（少请求打出强效果）

**目标优先级**：召唤者/仪式 > 高输出攻击者 > 可斩的低血 > 小怪；能斩召唤者就忽略小怪。

**杀→晕**：`calc.chain` 已算「按 `plans[].s` 杀谁→谁晕→省多少（`save`）」。`饥饿` 怪：杀它**同伴**才晕；多只饥饿杀任意同伴全晕，`taken` 已扣。`爪牙`：主人死→撤；2 回合内能杀本体直杀。

**其余机制**：眩晕窗口（骇鳗 ≤50%、仪式兽 ≤150）把爆发留给晕回合；荆棘先叠甲再多段；滑溜用多段；无实体先易伤；人工制品先用低价值 debuff 破；懒惰/缠结/限费（蛇行扼杀者）按最坏重算；死亡召唤（寄生蛙/活雾/雾魔）压到 15–25 等 AOE。

**聚焦 vs 分散**：总血 > 本回合伤害 → 聚焦「下回合能杀且威胁最高」那只；AOE 只补刀多只或破滑溜/无实体/人工制品。

**两回合账**：打完 `plans[].hp`、下回合入伤 I′；`H′ ≤ I′` → 必须挡满或斩杀；否则选「本回合净掉+下回合预期」最小的线；别为了等晕空过。

## 5. 血预算 / 药水 / SL

- **道中预算**：Act1 前 6 层 ≤5 血/场、整段 ≤20；Boss 前 ≥60%；燃烧之血战后 +6。
- **药水四问**：解什么｜槽满留不留｜会不会被打穿｜留给下场值不值。交：挡不住且净掉 ≥10% 最大生命｜斩杀差 5–15｜Boss 大攻击；单体/群体先核对。**Boss 不省药**，剩 ≥1 瓶 = 失误。
- **SL**：只在「全挡/斩杀/喝药」全不成立时用；常规战 ≤3 次，Boss 不占额度。流程 `save_and_quit` → `continue_run` → 重读 ctx。

## 6. 路线 / 非战斗

- 地图：`ctx.choice.opts` → `route --commit <i> --note "…"` → 每节点 `plan` 对账（PLAN_OK/REPLAN）。低血优先级：营火 > 问号 > 商店 > 怪 > 精英。
- 非战斗：读 `choice.eval` 的 `need/best/skip/buy/bar/why`（提示，非胜率）；冲突按牌面/手册，再 `do --option i`。事件读原文，地图走 route；`--full` 复盘。
- REPLAN：血线 <70%｜掉血 ≥20% 最大｜拿首张 AOE｜金币 100+｜牌组 +3｜多诅咒。**金币只删牌**；诅咒局拒绝全金币换牌。

## 7. 构筑

| 指标 | 目标 | 红线 |
|---|---|---|
| 张数 | Act1 14–18，Act2 ≤22 | >24 抽不到组合；Act1 第 10 层起 18 张封顶 |
| 打击 | ≤3 | 4 张进 Act2 = 稀释 |
| 防御 | Act2 前 ≥6；精英前 8+ 甲 ≥2 张 | 单回合格挡 < 精英入伤 = 必输 |
| AOE | 1–2 张 | 0 AOE = 多怪磨死 |
| 收尾 | 1 张（重锤/契约终结） | 无收尾 = 打不死 Boss |
| 运转 | Act2 前 4 + 2 回费 | 只有一套启动 = 死 |

只补缺口：**AOE > 主轴 > 防御 > 运转 > 收尾**；≥14 张只拿 A 级。奖励看 `cards` 的 `dmg/blk/draw/aoe`。

## 8. 精英 / Boss

```
T ≈ 敌血 ÷ 实际 DPS        N ≈ 敌入伤 − 稳定可挡
T × N > 当前血量×0.6 → 不打
```

- **Act1 Boss**：199 血 ÷ 15–18 伤 = 11–13 回合，Boss 19–33 伤/回合；不够别进。
- **斩杀排程**：先定第 T 回合杀；该回合 `HP + 甲 ≥ 爆炸/DeathBlow`（瀑布 41、44），不够就留 1 血、先叠甲再杀。
- **Act2 Boss**：399 ÷ 25–35 = 12–16 回合 + 每 3 回合一枚 Debuff → 要 ≥100 血 + 20+ 甲/回合 + ≤22 张。
- **Boss 前**：HP ≥70%、2 张 8+ 甲、牌组 ≤18（Act2 ≤22）、金币 ≤20、药水先验过。**精英闸**：60% 血 + 2 张 8+ 甲 + 1 张 AOE + 1 瓶药（召唤型 70% + AOE 能量预算）。

## 9. 工具坑

| 坑 | 做法 |
|---|---|
| 手牌会变 | `seq` 只写 `c`（id），不写下标 |
| `act` 手牌只剩 1–2 张 | 抽牌过渡态：`ctx.py` 复核再决策 |
| `use_potion` pending | 药水先进 CARD_SELECTION，`select_deck_card` 后生效 |
| `ok:false` | 用返回的 `ctx` 改 `seq` 重发；绝不硬 `end` |
| 费用被误算 | 回能/变费牌先打；`act` 逐步验算，不再整手预扣 |
| `mid:1` 且 `e=0` | 回合已结束：读下一回合 `ctx`；补 `end` 会被 act 拒 |
| 想连打省请求 | 杂怪 `{"auto":{"turns":N,"stop_hp":H}}` |
| 卡牌奖励 | `choose_reward_card --option i`，之后核对 `deck_n` |
| 药水目标 | `{"p":槽,"t":敌}`；漏 `t` 会 `invalid_target` |
| 台词 lint | `python tools/check_caster.py --say "…"` |

## 10. 反模式（见到就停）

**协议** ㉟不读 ctx 凭记忆出牌 ㊱seq 写下标 ㊲`ok:false` 后自己补 `end` ㊳无视 `calc.chain` 的免费晕
**数学** ①多怪只看一只 ②半挡半打 ③差 1–2 点没收 ④按旧斩杀线打 ⑤H′≤I′ 还换血
**防守** ⑥非斩杀回合全输出 ⑦有格挡牌却弃盾 ⑧对荆棘/高甲硬砍 ㉔7–10 入伤硬吃 ㉕药水带满不喝
**构筑** ⑩奖励全拿 ⑪删错牌 ⑫营火升打击/防御 ⑬三条轴混抓 ㉙大店只删 1 张又加 2 张
