# 铁甲战士 A10 · 决策 OS v10

> 数据优先级：`state` 实时（EFF / MECHANICS / BLOCK_POOL）> `db/sts2.db` > `docs/` 复盘 > 网络。
> 常驻只读本文件；查具体敌人才开 `references/enemies.md`（按幕/遭遇排）。
> 卡名用游戏内中文：Cinder=余烬、Hemokinesis=御血术、Sword Boomerang=飞剑回旋镖；**别用一代旧名**（煤渣/嗜血/愤怒/灰烬打击）。

## 0. 三条铁律（每回合先过，违反=送）

1. **先算死**：`incoming`（多怪加总）vs `HP + 当回合可挡 + 药水`，自伤牌也算进去。`incoming ≥ HP` → 全挡 / 斩杀 / 喝药，**禁止半挡半打**。
2. **小伤害必挡**：入伤 ≤8（80 血的 10% 线）→ 挡满，宁可少打一张刀；9–14 → 先吃满 `BLOCK_POOL`，差额才是换血额度；≥15 → 全挡 / 斩杀 / 喝药，禁止半挡半打。要吃伤写算式（省下回合 × 敌方单回合入伤 > 这次掉的血）。
3. **结束前三查**：energy=0/N｜没有能打的格挡牌（`BLOCK_POOL` 可挡 ≥ 入伤就先挡）｜没有能打的 0 费牌、没有「回合末扣血」牌（呼唤/诅咒/状态）。

> **防幻觉纪律**：数字只认当前 `state`（ANCHOR/EFF/BLOCK_POOL/POTIONS），不背旧局数字、不套旧版本结论；版本相关断言（药水/ mod 行为/卡面）标「已验证·日期」或「未验证」，未验证先花一步验证再下结论；拿不准就重读 state，不猜、不"应该是"。

## 1. 开局 60 秒

1. `state` 确认 MAIN_MENU；`obsctl.py status` 确认 `outputActive=false`。
2. 开录：`/reset` overlay → `tools/reload_overlay.py` → `obsctl.py free` → `start` → `health` 看出帧/静音；窗口化，别最小化。
3. `open_character_select` → IRONCLAD/A10 → `embark`；`route` → `route --commit <opt> --note "…"`（叠加层自动画 ROUTE，读路线快照 + 实时层数）。
4. Neow 四问：商店能补吗｜改善牌组还是临时资源｜HP 成本营火能兜住吗｜最坏能否接受。默认：**变 2 基础牌 > 删 1 > 金币 > 药水槽 > 升级**；永恒诅咒不拿；删 2 张的血价（-16）要算进开局血闸。
5. 开场白只谈这一局，**禁止**「上局/上次/第几局」。

## 2. 每回合 7 步（含步骤 0 战前准入）

```
0 战前准入：血闸（<50% 不接普通战｜<60% 不进精英｜<70% 不进 Boss）｜多怪闸（AOE=0 且敌≥3 → 精英不打）
   ｜机制闸（MECHANICS/INTENT_MEM/enemies.md 读不懂 → 不进、先查）
1 读 ANCHOR + self + 每只敌人（enemies/incoming/energy/hand、我的力量/虚弱/脆弱、敌 hp/block/powers）+ POTIONS 行（有药水先过 §4 四问）
2 读 MECHANICS + INTENT_MEM + enemies.md 对应行，写一句「机制 + 意图循环 + 最大单回合入伤」再出牌
3 量斩杀：EFF 的 ★斩 已含易伤/格挡/胆小/段数/荆棘；没 ★ 就自己算「敌 HP + 格挡 + 胆小 ≤ 总伤」
4 定回合类型：能斩→斩杀｜incoming ≥ HP→全挡/斩杀/喝药｜incoming ≤10% 最大生命→**挡满再输出**（宁可少打一张刀）｜否则→先吃满手牌格挡池，净掉压到 ≤5（拿不准 ≤10%）
   药水闸：挡不住 / 入伤 ≥25% 最大生命 / 这回合不交就死人 → 交药水（§4 药水四问）
5 排序：0 费/抽牌/回费 → 易伤/虚弱/力量 → AOE → 单体收尾；ORDER 先易伤，BLOCK_POOL 够挡先挡满
6 出一张 → 重读 state（手牌索引/能量/敌人死没死/意图都变）；同名多级打升级版，指定用 --card
7 收尾三查 + 能量打空（可打就出，**0 费牌必打**；全不可打/能量保留遗物例外）+ 处理 WASTE_ENERGY / LEFT_BLOCK_ON_TABLE + 一条梗
```

**HAND_STALE** = 过渡快照：手牌空但 play_card 合法，必须重读再决策。**play_card 失败/WAIT 时绝不接 end_turn**（会连带执行、白掉回合）：重读 state 再打。**VALUE_RANK**：同费先高伤/高甲；打击只打差值正好/留大牌/只剩它。

## 3. 数值与斩杀

```
单卡伤害 = state 的实时 Damage（已含力量/虚弱/遗物）
修正：敌易伤 ×1.5｜我虚弱 ×0.75｜我脆弱 格挡 ×0.75｜敌格挡先扣｜胆小首击 +6/7｜荆棘每段反伤
多段：每段独立吃格挡/胆小/荆棘；飞剑 3×3、双发 5×2 都要乘段数
斩杀写成数字：敌 HP + 格挡 + 胆小 ≤ 本回合总伤害
```

- **别心算**：`EFF`/`ANCHOR` 就是答案；挂上易伤/力量后立刻重读（6→9、8→12）。
- **机制**：滑溜/无实体/**胆小**→多段或 AOE 破；硬化→打满 20 停手叠甲；人工制品→剥；**荆棘→反伤，甲不够别砍**。
- **自伤牌**：狱火（每回合 -1）、血墙（-2）、御血术（-2）、放血（-3）、祭品（-6）、突破（-1）、烙印（-1）。**HP ≤3 先算这一下会不会直接死**。
- **手里的状态**：感染/黏液回合末 3 伤/张（可被格挡吸收）；呼唤 6 伤/张（**无视格挡，必须打掉**）。
**每费价值**：飞剑+ 12｜耸肩+ 11｜飞剑 9｜余烬 9｜上勾拳 6.5｜打击 6｜防御 5｜御血术 15。

## 4. 血预算 / 药水 / SL

- **战前血闸（硬）**：<50% 只接营火/事件，不接普通战；<60% 不进精英；<70% 不进 Boss；<40% 普通战也全挡。**两回合账**：打完剩 H′、下回合入伤 I′，H′≤I′ 这回合必须挡满或斩杀。
- 道中预算：Act1 前 6 层普通怪 ≤5 血/场、整段 ≤20；有营火段 ≤10；Boss 前 ≥60%（理想 70%）。Burning Blood 战后 +6。
- **多怪闸（硬）**：AOE=0 且敌≥3 → 精英/高难战不打；`有效 DPS（含 AOE/多段）× 可活回合 < 敌总血` → 不打。多怪精英先算「每回合有效伤害」：<10 且入伤 >15 → 绕路。
- **药水（先验再规划）**：四问——解什么｜槽满留不留｜这回合会不会被打穿｜留给下场值不值。**交**：挡不住且净掉 ≥10% 最大生命｜斩杀差 5–15｜Boss 大攻击回合｜精英 T1 <60%。**留**：T1 满血、入伤 ≤10%、下一格营火。**先验**：pending 且重读后状态不变 = 本版本无效（v0.8.0+v0.107.1 实测），此后按 0 药水算。细则 `references/potions.md`。
- **SL 只在必死**（全挡/斩杀/喝药都不成立），每次录像 ≤3 次；重打换决策，配一句俏皮话。

## 5. 路线

```
route                       # 排序（含 HP/防御数/AOE/药水）+ ELITE_GATE
route --commit 0 --note "…"  # 记成计划（logs/route_plan.json 存快照）
plan                        # 对账：PLAN_OK / REPLAN
```

- **commit 前逐条扫下游**：不只看分数——找每条路径里「**唯一出口是精英**」的节点（单出口精英=强制赌血），低血时降权/换线；第 44 局就是 8 层单出口四园丁。
- **REPLAN 触发**：血线跌破 70%（<50% 下一格必须营火）｜本段掉血 ≥20% 最大｜防御跨过 6 张｜拿到首张 AOE｜药水用光｜金币 100+｜牌组 +3 张｜多诅咒。
- **选节点前重读 AVAILABLE**（凭记忆按下标 = 踩雷）；低血优先级：营火 > 问号 > 商店 > 怪 > 精英。
- **多营火优先**：同分选营火多的线，但要看位置——前 8 层只有 1 个营火、后面连打 3 场会中途见底。
- **非必要不精英**：三闸全「是」也只当备选，再叠总账；**血量经济**：5–10 血换小怪可、15–25 血换精英可、30+ 血是警报。
- **商店**：药水 > 删牌 > 遗物 > 卡；100+ 金就规划。**营火**：<50% 必睡，≥70% 必锻，50–70% 看下一格。

## 6. 构筑

| 指标 | 目标 | 红线 |
|---|---|---|
| 张数 | Act1 12–15，最终 16–18 | **>18 只拿质变**（引擎/大甲/AOE/收尾），普通好牌也 skip |
| 打击 | Act1 ≤4，Act2 前 ≤3 | 5 张进 Act2 = 稀释 |
| 防御 | 进 Act2 ≥6 张，其中 2 张 8+ | 单回合最大格挡 < 精英每回合入伤 = 结构性必输 |
| AOE | 1–2 张 | 0 AOE = 多怪战被磨死（42/44 局死因） |
| 收尾 | 1 张（重锤/余烬/完美打击/全身撞击/恶魔之焰） | 无收尾 = 烧得爽但打不死 |
| 运转 | Act2 前 4 运转 + 2 回费 | 只有一套启动 = 死 |

**抓牌默认跳过**：只补缺口（AOE/易伤/防御/运转/收尾）；牌组 ≥14 只拿 A 级，≥16 只拿质变；**`skip_reward_cards` 也会加卡（§9），牌组会膨胀**。
**按缺口抓**：**AOE 第一优先**（闪电霹雳/突破/契约终结/恶魔之焰；0 AOE 时 AOE > 任何单卡）> 主轴核心（腐化/主宰/黑暗之拥/无惧疼痛）> 防御（岿然不动/火焰屏障/巨像/耸肩/坚毅）> 运转（燃烧契约/剑柄/战斗专注/祭品/放血）> 收尾（完美打击/全身撞击/重锤）。数值查 `references/cards.md`。

**循环解（剑耸）**：2 抽牌（剑柄/耸肩/劫掠/怨恨/契约）+ 1 加费（放血/仪式）互抽；战士缺抽不缺费。清单 `references/archetypes.md`。
**主轴二选一**：**消耗流**=腐化+黑暗之拥+无惧疼痛+契约终结（燃料：燃烧契约/坚毅/祭品）｜**主宰易伤流**=主宰+凶恶+残酷+欺凌+痛击/挑衅/上勾拳。**血墙不抓**：15+ 甲优先岿然、火焰屏障、巨像+易伤。
**升级**：痛击 8→10（+1 层易伤）｜耸肩 8→11｜坚毅 7→9（随机→定向）｜剑柄 9→10+抽 2｜全身撞击 1→0 费。
**流派强度**：S 消耗 > A 力量 ≈ A 格挡 > B 易伤；`references/builds_tier.md`。
**自伤联动**：狱火 + 放血/突破，多怪与破滑溜好用。

**删牌**：先买卡/遗物，钱没处花再删；重振/地狱狂徒先来删打，狂怒/劫掠先来删防；无脑删打/删防都错。
**整局目标**：Act1 结束 HP≥70%、12–15 张、1–2 AOE、有 1 张收尾；Act2 15–18 张、4 运转 2 回费、基础牌 ≤3。

## 7. 敌人（细节按幕查 `references/enemies.md` v3）

1. **召唤者**：本体 2 回合内能杀 → 直杀本体，否则先清爪牙（本体死爪牙消失）。
2. **荆棘/反伤** 先叠格挡再多段；**胆小/滑溜/无实体** 用 AOE/多段破；多怪精英没 AOE 不进。
3. **Buff/Stun 回合不是安全回合**：按下一击留血线；成长型（仪式/力量）先杀。

详细行（含 Boss）查 `references/enemies.md`，**Boss 行必读**。

## 8. 精英 / Boss 总账

```
T ≈ 敌血 ÷ 我的实际 DPS（含力量/易伤）
N ≈ 敌入伤 − 我能稳定挡下的
T × N > 当前血量 × 0.6 → 不打，不管三闸多绿、遗物多香
```

- **进 Boss 前算回合数**：`敌血 ÷ 实际 DPS > 我能活的回合数` → 不硬进（48 局 38 血/30 张牌进 399 血 Boss，30 伤/回合要 13 回合，必输）。
- **Act1 Boss DPS 闸**：199 血祭司 / 262 血仪式兽 ÷ 15–18 伤 = 11–13 回合，而 Boss 每回合 19–33 → 必输（50 局）。不够先补收尾牌 + 2 张 8+ 格挡，别带 3 张打击进 Boss。

- **三闸只是必要条件**，再加两条：单回合最大格挡 ≥ 敌方每回合入伤；HP ≥70%。
- **药水时机**：T1 不是喝药时刻，留断档/必杀回合；低血遇强制精英 T1 就交。
- **Boss 前**：HP≥70%、2 张 8+ 防御、药水可用、金币 ≤20、牌组 ≤18；能补到 80% 更稳。
- **单回合格挡上限**：Act1 Boss 单回合 20–26 伤，进 Boss 前至少 2 张单卡 15+ 防御；**昏眩/Ringing 回合只能出 1 张**，进昏眩前 HP > Boss 最大单回合攻击。

- **A1 Boss 时序**：瀑布巨兽 Buff→…→**Stun（白给，别交甲）**→**DeathBlow 44**（应急按钮留到 DeathBlow 回合；30<44 需 HP≥14）｜仪式兽 150 晕 + Ringing｜神官先杀本体｜墨影 滑溜 9 用多段｜异鱼 无实体 2 + 呼唤必打｜族母 睡 3 回合。
- **Buff/Stun/Heal 回合不交防御资源**：先看 INTENT 这回合是否真打人；Stun 回合交应急按钮 = 白丢 + 下回合被封甲。

## 9. 工具坑

| 坑 | 做法 |
|---|---|
| `end_turn` 快照还没抽牌 | 决策前一律 `state` 重读；`HAND_STALE` 就是提示 |
| **play_card 返回 WAIT/失败** | **绝不接 `end_turn`**（会连带执行、白掉回合）：重读 state 再打同一张 |
| 工具报错（invalid_target / invalid_action） | **先自修**：缺目标自动选最低血敌人；play_card 失败重读后重试 1 次；两次都失败才换牌/报错 |
| 打完牌不重读 | 挂易伤/力量后立刻重读 EFF（斩杀线会变） |
| 牌面文字和本地库不一致 | **以实时 `resolved_rules_text` 为准** |
| 手牌索引会变 | 每张牌后重读；单张 `play <CARD_ID>`，多张 `do play_card --card <i>` |
| 多段意图 | 看 `ANCHOR` 的 `dmg=8x4=32`，按较大值挡 |
| 药水 | `--option` 是槽位号；要目标时 `--target`（不填自动选最低血）；pending 先重读看 `is_queued`，最多重试 1 次 |
| 多选界面 | 看 `SELECTION_STATE`；一次点完 `--options 0,2`；同一张不能点两次 |
| 卡牌奖励 | `skip_reward_cards`/`resolve_rewards` **也会加卡进牌组**（48 局 12→30）；只用 `choose_reward_card --option i`，奖励后核对 `deck N`；别用 `collect_rewards_and_proceed` |
| 下标连打 | `--card` 前必须看到 `state` 那一行（48 局 4 次错位） |
| 选项下标 | 先读 `opt[i]` 中文；光/暗之门 0=随机升级 1=删牌 |
| 录制没声 / 没画面 | `obsctl.py health`：看出帧/静音/最小化；`free` 切采集、`nomute` 关静音 |
| PowerShell | 不支持 `&&`；`--meme` 别放英文双引号；中文乱码写文件再读 |

## 10. 反模式（见到就停）

**数学**：① 多怪只看一只｜② 半挡半打｜③ 差 1–2 点没收掉｜④ 不重读就按旧斩杀线打｜⑤ 下一回合会死（H′≤I′）还在换血。
**防守**：⑥ 非斩杀回合全输出｜⑦ 有格挡牌却弃盾结束回合｜⑧ 对荆棘/高甲硬砍｜⑨ 预斩杀回合不叠盾｜㉔ 入伤 7–10 用「抢节奏」当借口硬吃（49 局原话）｜㉕ 药水带满一局不喝。
**构筑**：⑩ 奖励全拿、18+ 张｜⑪ 有移除机会却删打击/跳过｜⑫ 营火升打击/防御｜⑬ 三条轴混抓。
**决策**：⑭ 进精英/Boss 不算总账｜⑮ 药水等血见底｜⑯ 凭记忆点下标｜⑰ 低血选「出口是精英」｜㉑ 低血接战 / 0 AOE 进多怪精英｜㉒ 只看分数不看下游单出口精英。
**操作**：⑱ 有费空过｜⑲ 开场白谈上局｜⑳ 梗刷屏或哑火｜㉓ play 失败后直接 end_turn｜㉖ 药水 pending 后还按「有药」规划（50 局）｜㉗ 一条命令连打两张牌（WAIT 后白丢一张）。
