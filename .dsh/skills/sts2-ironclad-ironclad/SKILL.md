## 0. 三条铁律

1. **先算死**：`incoming`（多怪加总）× vs `HP + 可挡 + 药水`，自伤也算。`incoming ≥ HP` → 全挡 / 斩杀 / 喝药，**禁止半挡半打**。
2. **小伤害必挡**：≤8（80 血的 10% 线）→ 挡满，宁可少打一张刀；9–14 → 先吃满 `BLOCK_POOL`，差额才是换血额度；≥15 → 全挡 / 斩杀 / 喝药。要吃伤写算式（省下回合 × 敌方单回合入伤 > 这次掉的血）。
3. **结束前三查**：energy=0/N｜没有能打的格挡牌｜没有能打的 0 费牌、没有「回合末扣血」牌（呼唤/诅咒/状态）。

> **防幻觉纪律**：数字只认当前 `state`（ANCHOR/EFF/BLOCK_POOL/POTIONS）；不背旧局数字、不套旧版本结论；版本相关断言（药水/mod/卡面）标「已验证·日期」或「未验证」，未验证先花一步验证；拿不准就重读，不猜。

## 2. 每回合 7 步（含步骤 0 战前准入）

```
0 战前准入：血闸（<50% 不接普通战｜<60% 不进精英｜<70% 不进 Boss）｜多怪闸（AOE=0 且敌≥3 → 精英不打）｜机制闸（读不懂就不进，先查）
1 读 ANCHOR + self + 每只敌人 + POTIONS 行（有药水先过 §4 四问）
2 读 MECHANICS + INTENT_MEM + enemies.md 对应行，写一句「机制 + 意图循环 + 最大单回合入伤」再出牌
3 量斩杀：EFF 的 ★斩 已含易伤/格挡/胆小/段数/荆棘；没 ★ 就自己算「敌 HP + 格挡 + 胆小 ≤ 总伤」
4 定回合类型：能斩→斩杀｜incoming ≥ HP→全挡/斩杀/喝药｜≤10% 最大生命→挡满再输出｜否则→吃满格挡池，净掉压到 ≤5
5 排序：0 费/抽牌/回费 → 易伤/虚弱/力量 → AOE → 单体收尾；ORDER 先易伤，BLOCK_POOL 够挡先挡满
6 出一张 → 重读 state；同名多级打升级版，指定用 --card；**一条命令只打一张牌**
7 收尾三查 + 能量打空（0 费牌必打）+ 处理 WASTE_ENERGY / LEFT_BLOCK_ON_TABLE + 一条梗
```

**HAND_STALE**（手牌空但 play_card 合法）= 过渡快照，必须重读。**play_card 失败/WAIT 绝不接 `end_turn`**：重读再打。**VALUE_RANK**：同费先高伤/高甲；打击只打差值正好/留大牌/只剩它。

## 3. 数值与斩杀

```
单卡伤害 = state 的实时 Damage（已含力量/虚弱/遗物）
修正：敌易伤 ×1.5｜我虚弱 ×0.75｜我脆弱 格挡 ×0.75｜敌格挡先扣｜胆小首击 +6/7｜荆棘每段反伤
多段：每段独立吃格挡/胆小/荆棘；飞剑 3×3、双发 5×2 都要乘段数
斩杀写成数字：敌 HP + 格挡 + 胆小 ≤ 本回合总伤害
```

- **别心算**：`EFF`/`ANCHOR` 就是答案；挂易伤/力量后立刻重读（6→9、8→12）。
- **机制**：滑溜/无实体/胆小→多段或 AOE 破；硬化→打满 20 停手叠甲；人工制品→先剥；荆棘→反伤，甲不够别砍。
- **自伤**：狱火 -1/回合、血墙 -2、御血术 -2、放血 -3、祭品 -6、突破 -1、烙印 -1；**HP ≤3 先算会不会直接死**。
- **状态牌**：感染/黏液回合末 3 伤/张（可挡）；呼唤 6 伤/张（**无视格挡，必须打掉**）。
- **每费价值**：飞剑+ 12｜耸肩+ 11｜飞剑 9｜余烬 9｜上勾拳 6.5｜打击 6｜防御 5｜御血术 15。

## 4. 血预算 / 药水 / SL

- **血闸（硬）**：<50% 只接营火/事件；<60% 不进精英；<70% 不进 Boss；<40% 普通战也全挡。**两回合账**：打完 H′、下回合入伤 I′，H′≤I′ 这回合必须挡满或斩杀。
- **道中预算**：Act1 前 6 层普通怪 ≤5 血/场、整段 ≤20；Boss 前 ≥60%（理想 70%）。Burning Blood 战后 +6。
- **药水（先验再规划）**：四问——解什么｜槽满留不留｜这回合会不会被打穿｜留给下场值不值。**交**：挡不住且净掉 ≥10% 最大生命｜斩杀差 5–15｜Boss 大攻击回合｜精英 T1 <60%。**留**：T1 满血、入伤 ≤10%、下一格营火。**先验**：pending 且重读后状态不变 = 本版本无效（v0.8.0+v0.107.1 实测），此后按 0 药水算。细则 `references/potions.md`。
- **SL 只在必死**（全挡/斩杀/喝药都不成立），每录像 ≤3 次；重打换决策。

## 5. 路线

`route` → `route --commit <opt> --note "…"` → 每节点 `plan` 对账（PLAN_OK / REPLAN）。

- commit 前扫「唯一出口是精英」的节点；低血优先级 营火 > 问号 > 商店 > 怪 > 精英。
- REPLAN 触发：血线 <70%｜掉血 ≥20% 最大｜拿到首张 AOE｜金币 100+｜牌组 +3｜多诅咒。
- **非必要不精英**：三闸全「是」也只当备选；血量经济 5–10 换小怪、15–25 换精英、30+ 报警。

细节（商店顺序/营火策略/多营火取舍）→ `references/playbook.md` §1。

## 6. 构筑

| 指标 | 目标 | 红线 |
|---|---|---|
| 张数 | Act1 12–15，最终 16–18 | >18 只拿质变 |
| 打击 | Act1 ≤4 | 5 张进 Act2 = 稀释 |
| 防御 | 进 Act2 ≥6，2 张 8+ | 单回合格挡 < 精英入伤 = 必输 |
| AOE | 1–2 张 | 0 AOE = 多怪磨死 |
| 收尾 | 1 张 | 无收尾 = 打不死 Boss |
| 运转 | Act2 前 4 + 2 回费 | 只有一套启动 = 死 |

只补缺口：**AOE > 主轴核心 > 防御 > 运转 > 收尾**；≥14 张只拿 A 级；`skip_reward_cards` 也会加卡。细节（流派/升级/删牌）→ `references/playbook.md` §2。

## 7. 敌人

1. **召唤者**：本体 2 回合内能杀→直杀本体，否则先清爪牙（本体死爪牙撤退）。
2. **荆棘/反伤** 先叠格挡再多段；**胆小/滑溜/无实体** 用 AOE/多段破。
3. **Buff/Stun 回合不是安全回合**：按下一击留血线；成长型（仪式/力量）先杀。

行级数据查 `references/enemies.md`（**Boss 行必读**），时序细节 `references/playbook.md` §3。

## 8. 精英 / Boss 总账

```
T ≈ 敌血 ÷ 我的实际 DPS    N ≈ 敌入伤 − 我能稳定挡下的
T × N > 当前血量 × 0.6 → 不打
```

- **Act1 Boss DPS 闸**：199 血祭司 / 262 血仪式兽 ÷ 15–18 伤 = 11–13 回合，而 Boss 每回合 19–33 → 必输（50 局）。不够先补收尾牌 + 2 张 8+ 格挡。
- **Boss 前**：HP≥70%、2 张 8+ 防御、牌组 ≤18、金币 ≤20、药水先验过。
- **Buff/Stun/Heal 回合不交防御资源**；**昏眩/Ringing 回合只能出 1 张**。

时序与清单 → `references/playbook.md` §4。

## 10. 反模式（见到就停）

**数学**：① 多怪只看一只｜② 半挡半打｜③ 差 1–2 点没收掉｜④ 不重读按旧斩杀线打｜⑤ H′≤I′ 还在换血。
**防守**：⑥ 非斩杀回合全输出｜⑦ 有格挡牌却弃盾｜⑧ 对荆棘/高甲硬砍｜㉔ 入伤 7–10 用"抢节奏"硬吃｜㉕ 药水带满不喝。
**构筑**：⑩ 奖励全拿 18+ 张｜⑪ 删错牌｜⑫ 营火升打击/防御｜⑬ 三条轴混抓。
