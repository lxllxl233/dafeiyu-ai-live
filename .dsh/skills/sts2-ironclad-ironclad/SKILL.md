# 铁甲战士 A10 · 决策 OS v17

> 常驻只有本文件，细节按需抓 references/（**别整份加载**）。
> `state` 只打增量：药水/遗物/机制/卡面说明**只在变化时出现**；要全量用 `state --full`。

## 0. 三条铁律

1. **先算死**：`incoming`（多怪加总，自伤也算）vs `HP + 可挡 + 药水`。`incoming ≥ HP` → 全挡 / 斩杀 / 喝药，**禁止半挡半打**。
2. **小伤害必挡**：≤8 挡满；9–14 先吃满 `BLOCK_POOL`，差额才是换血额度；≥15 全挡 / 斩杀 / 喝药。
3. **结束前三查**：energy=0/N｜没有能打的格挡牌｜没有能打的 0 费牌、没有「回合末扣血」牌。

> **防幻觉**：数字只认当前 `state`（ANCHOR/EFF/BLOCK_POOL/HUD/LEGAL）；版本相关断言标「已验证·日期」或「未验证」；拿不准就重读，不猜。

## 1. 准入闸（进战斗/精英/事件前）

- **血闸**：<50% 只接营火/事件｜<60% 不进精英（召唤型 70%）｜<70% 不进 Boss。**强制精英不看闸**：路线里「唯一出口是精英」就先算这条线要 ≥60% 血。
- **多怪闸**：AOE=0 且敌 ≥3 → 不进精英。
- **换血闸**：花血换 relic/金币，先答「Act1 内回得了本吗」——+1 最大生命/场最多回 5–8 点，不值 14 点现血。

## 2. 每回合 7 步

```
1 ANCHOR + HUD + 每只敌人意图 + POTIONS（有药先过四问）
2 读 MECHANICS/INTENT_MEM（只在变化时出现；没有就是已读过），写一句「机制+意图循环」
3 量斩杀：★斩已含易伤/格挡/胆小/段数/荆棘；没 ★ 就自己算「敌 HP+格挡+胆小 ≤ 总伤」
4 定回合类型：斩杀｜incoming≥HP 全挡/喝药｜≤10% 最大生命挡满｜否则吃满格挡池、净掉 ≤5
5 排序：0 费/抽牌/回费 → 易伤/虚弱/力量 → AOE → 单体收尾
6 出牌：**一条命令只打一张**（`play_card`；确定顺序的 0 风险连招可用 `batch`，见 §9）
7 收尾：0 费打完 → energy 打空 → 无敌方回合末扣血 → 留钩子到斩杀
```

**STATE_STALE/WAIT/ACTION_SKIPPED**：绝不接 `end_turn`，重读再打。手牌下标每张都会变，`--card` 前必须看到当前 `state`。

## 3. 数值与斩杀

```
单卡伤害 = state 实时 Damage（已含力量/虚弱/遗物）
修正：易伤 ×1.5｜我虚弱 ×0.75｜我脆弱 格挡 ×0.75｜敌格挡先扣｜胆小首击 +6/7｜荆棘每段反伤
多段：每段独立吃格挡/胆小/荆棘（飞剑 3×3、双发 5×2 要乘段数）
斩杀写成数字：敌 HP + 格挡 + 胆小 ≤ 本回合总伤
```

- **AOE 清算**：AOE 总量 A vs 全场血 H。A≥H = 清场回合（先易伤/降费/抽牌，再一发收）；A<H 先算残血、收最危险的 1–2 只；N=1 别对单体放 AOE；召唤型敌人在召唤前留 AOE+能量。
- **能量纪律**：结束 `energy` 必须 0，或逐张写明「不可打/零收益」；**0 费攻击必打**；顺序「0 费 → 1 费刀/盾 → 确认 0 能量」。
- **自伤四问**（放血/祭品/血墙/突破口）：这 2–6 血换的能量本回合能斩杀或挡 ≥ 自伤吗？HP ≤40% 默认不交；有别的能量来源就不交；交完下回合还够活吗？
- **状态牌**：感染/黏液 3 伤、呼唤 6 伤（无视格挡）——全算进 incoming。
- **每费价值**：飞剑+ 12｜耸肩+ 11｜飞剑 9｜余烬 9｜上勾拳 6.5｜打击 6｜防御 5。

## 4. 血预算 / 药水 / SL

- **两回合账**：打完 H′、下回合入伤 I′，`H′ ≤ I′` 这回合必须挡满或斩杀。
- **道中预算**：Act1 前 6 层 ≤5 血/场、整段 ≤20；Boss 前 ≥60%（理想 70%）；燃烧之血战后 +6。
- **药水四问**：解什么｜槽满留不留｜这回合会不会被打穿｜留给下场值不值。**交**：挡不住且净掉 ≥10% 最大生命｜斩杀差 5–15｜Boss 大攻击回合。**先核对单体/群体**——描述里「敌人」是单数就只作用一只。
- **调用必带目标**：`use_potion --option <槽> --target <敌下标>`（漏 `--target` = `invalid_target`，别再当「药水无效」）。
- **SL**：只在「全挡/斩杀/喝药」全不成立时用；读档前先答「这次我哪一手不同」。常规战每局 ≤3 次，Boss 不占额度。流程 `save_and_quit` → 主菜单 `continue_run` → 重读 state（牌序可能重洗）。开场立账「SL 常规 0/3」。

## 5. 路线

`route` → `route --commit <opt> --note "…"` → 每节点 `plan` 对账（PLAN_OK / REPLAN）。

- commit 前扫「唯一出口是精英」的节点；低血优先级：营火 > 问号 > 商店 > 怪 > 精英。
- REPLAN 触发：血线 <70%｜掉血 ≥20% 最大｜拿首张 AOE｜金币 100+｜牌组 +3｜多诅咒。
- **金币只有一个用途：删牌**。有诅咒时，「交出全部金币换牌面变化」的事件一律拒绝。

## 6. 构筑

| 指标 | 目标 | 红线 |
|---|---|---|
| 张数 | Act1 14–18，Act2 ≤22 | >24 = 抽不到组合；Act1 第 10 层起 18 张封顶 |
| 打击 | ≤3 | 4 张进 Act2 = 稀释 |
| 防御 | Act2 前 ≥6，精英前 8+ 甲 ≥2 张 | 单回合格挡 < 精英入伤 = 必输 |
| AOE | 1–2 张 | 0 AOE = 多怪磨死 |
| 收尾 | 1 张（重锤/契约终结） | 无收尾 = 打不死 Boss |
| 运转 | Act2 前 4 + 2 回费 | 只有一套启动 = 死 |

只补缺口：**AOE > 主轴核心 > 防御 > 运转 > 收尾**；≥14 张只拿 A 级。

## 7. 敌人

1. **召唤者**：本体 2 回合内能杀→直杀本体；否则先清爪牙（本体死爪牙撤）。
2. **荆棘/反伤**先叠甲再多段；**胆小/滑溜/无实体**用 AOE/多段破；**人工制品**先剥。
3. **Buff/Stun 回合不是安全回合**：按下一击留血线；成长型（力量/仪式）先杀。
4. **死亡召唤型精英（寄生蛙/活雾/雾魔）杀前必答**：这一手有 AOE + ≥3 能量吗？没有就压血不杀（留 15–25），等 AOE 再收。
5. **紧缠型/限费型**（蛇行扼杀者、缠结 +1 费、懒惰限 3 张）：当回合按最坏重算。

行级数据查 `references/enemies.md`（Boss 行必读）。

## 8. 精英 / Boss

```
T ≈ 敌血 ÷ 实际 DPS    N ≈ 敌入伤 − 稳定可挡
T × N > 当前血量 × 0.6 → 不打
```

- **Act1 Boss DPS 闸**：199 血 ÷ 15–18 伤 = 11–13 回合，而 Boss 19–33 伤/回合 → 不够就别进。
- **Act2 Boss**：399 血 ÷ 25–35 = 12–16 回合 + 每 3 回合一枚 Debuff（少抽 1/限 3 张/-1 费）→ 要 ≥100 血 + 20+ 甲/回合 + ≤22 张。
- **Boss 前**：HP ≥70%、2 张 8+ 甲、牌组 ≤18（Act2 ≤22）、金币 ≤20、药水先验过。
- **精英闸**：60% 血 + 2 张 8+ 甲 + 1 张 AOE + 1 瓶药（召唤型 70% + AOE 能量预算）。

## 9. 工具坑

| 坑 | 做法 |
|---|---|
| `end_turn` 快照没抽牌 | 先 `state` 重读 |
| `play_card` 失败/WAIT | 绝不接 `end_turn`，重读再打 |
| 连打两张被吞 | 一条命令只打一张；**确定顺序时用 `batch`**（客户端每步等快照、按 `card_id` 找牌、有异常就停） |
| 手牌下标会变 | 每张重读；`play <CARD_ID>` 或 `batch` 的 `card_id` 更安全 |
| 卡牌奖励 | 只用 `choose_reward_card --option i`，之后核对 `deck N` |
| 想看全量 | `state --full`（药水/遗物/卡面说明一次打全） |

`batch` 用法（同一回合、顺序确定、有风险就别用）：
```powershell
python sts2.py batch '{"actions":[{"action":"play_card","card_id":"BASH","target_index":0,"thought":"…"},{"action":"play_card","card_id":"DISMANTLE","target_index":0}]}'
```

## 10. 反模式（见到就停）

**数学**：① 多怪只看一只｜② 半挡半打｜③ 差 1–2 点没收掉｜④ 不重读按旧斩杀线打｜⑤ H′≤I′ 还在换血。
**防守**：⑥ 非斩杀回合全输出｜⑦ 有格挡牌却弃盾｜⑧ 对荆棘/高甲硬砍｜㉔ 入伤 7–10 用「抢节奏」硬吃｜㉕ 药水带满不喝。
**构筑**：⑩ 奖励全拿｜⑪ 删错牌｜⑫ 营火升打击/防御｜⑬ 三条轴混抓｜㉙ 大店只删 1 张又加 2 张。
**操作**：⑭ 不算总账进精英/Boss｜⑯ 凭记忆点下标｜⑱ 有费空过｜㉓ play 失败直接 end_turn｜㉖ `use_potion` 漏 `--target`｜㉜ 0 费攻击留手里｜㉝ 无收益自伤｜㉞ 血换 relic 不回本。

## 13. 本季教训（v17 · 第 56 局）

1. **金币只有一种用法：删牌**（56）：已有诅咒时「全金币换变化」= 诅咒洗成诅咒 + 永远删不了牌。
2. **强制精英不看血闸**（56 第 12/14 层）：路线里唯一出口是精英，就必须提前把血养到 60%。
3. **召唤型精英杀前一句**（54/56）：寄生蛙死召 4 只共 79 血；杀它那手没 AOE+能量 = 白给两回合。
4. **状态牌是隐形血税**：感染/黏液 3、呼唤 6；56 局两回合空手 -21。
5. **Act1 第 10 层起 18 张封顶**：20 张 + 2 诅咒 = 连续空手。
6. **血换 relic 看回本**：+1 最大生命/场在 Act1 最多回 5–8 点，不值 14 点现血。
7. **AOE 清场公式**：A≥H 才清场，A<H 收最危险的 1–2 只，N=1 不用 AOE。
8. **能量打空、0 费先打**：1 费躺手里 = 白丢 6–9 伤。
9. **自伤只在「本回合斩杀/挡 ≥ 自伤」时交**，HP ≤40% 不交。
10. **血量两件套（53 局打穿 Act1 的配置）**：狂宴（击杀 +4 最大生命）+ 黑暗之血（战后 +12），见到就拿。
