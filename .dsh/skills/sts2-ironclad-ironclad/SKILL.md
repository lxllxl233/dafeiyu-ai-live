# 铁甲战士 A10 · 决策 OS v18

> 常驻只有本文件；references 只在触发时 `read`（带 offset/limit，**别整份读**）。
> v18 与 v17.1 决策内容一致，只把「每刀一条命令」改成「一回合一条命令」。

## 0. 传输协议：一回合 = 1 次 batch

```powershell
python sts2.py state   # 只在：进战斗 / 读档 / 上一条 batch 没给快照
python sts2.py batch '{"actions":[
 {"action":"play_card","card_id":"BASH","target_index":0,"thought":"它 12，先破甲","meme":"先算账再摸牌"},
 {"action":"play_card","card_id":"STRIKE_IRONCLAD","target_index":0},
 {"action":"end_turn","thought":"…","meme":"…"}]}'
```

- **回显**：每刀一行 `[i] play_card 0 -> completed | E3→2 · e0:41 · hand4`，末尾是**下一回合完整快照**（TURN/HAND/BLOCK_POOL/ENEMIES/LEGAL）。下一回合直接用它决策，**不再 state**。
- **安全在工具里，不在重复读数里**：`card_id` 每步按当前手牌重解析（手牌压缩不打错）；缺牌 `BATCH STOP`；超费 `PLAN_OVER_BUDGET`（动手前整手拒）；目标已死自动改打最低血活敌；最后一刀打完，`end_turn` 自动跳过。
- **见 `BATCH STOP` / `PLAN_OVER_BUDGET`**：用回显快照改计划重发，**绝不接 `end_turn` 硬收**（= 白挨一轮）。
- **只有三种情况退回单张 `play`**：要靠抽牌/弃牌才能定下一步；要等 Buff/Debuff 落地；batch 中途停过。其余一律整回合 batch。
- 每刀都要 `thought`/`meme`（说话规则看 `sts2-caster`；写完可 `python tools/check_caster.py --say "…"` 过一遍 lint），别写成报告体。

## 0.5 记忆分层（省上下文的另一半）

| 层 | 命令 | 体积 | 何时 |
|---|---|---|---|
| L1 结构化记忆 | `sts2.py memory`（`--write` 落盘） | ~150 tok | 开局/换幕/新 session/每 4–5 层 |
| L2 当前状态 | `state` 或 batch 尾部快照 | 90–350 tok | 每回合 1 次 |
| L3 细节 | `journal --floor N --last 20` | 按需 | 复盘、想不起某层怎么掉的 |

- 新 session 恢复：`memory` + 一条快照就够，别翻旧对话。
- **每幕结束：`memory --write`，然后开新会话续跑**——旧 transcript 不再被每次请求重读，这是单笔最大的一省。
- `logs/run_*.jsonl`、战报 md **永不进上下文**。

## 1. 三条铁律

1. **先算死**：`incoming`（多怪加总，自伤也算）vs `HP + 可挡 + 药水`。`incoming ≥ HP` → 全挡 / 斩杀 / 喝药，**禁半挡半打**。
2. **小伤害必挡**：≤8 挡满；9–14 先吃满 `BLOCK_POOL`，差额才是换血额度；≥15 全挡 / 斩杀 / 喝药。
3. **结束前三查**：energy=0/N｜没有能打的格挡牌｜没有能打的 0 费牌、没有「回合末扣血」牌。

> **防幻觉**：数字只认当前快照（ANCHOR/EFF/BLOCK_POOL/HUD/LEGAL）；版本断言标「已验证·日期」或「未验证」；拿不准重读，不猜。

## 2. 准入闸

- **血闸**：<50% 只接营火/事件｜<60% 不进精英（召唤型 70%）｜<70% 不进 Boss。唯一出口是精英 → 先把血养到 ≥60%。
- **多怪闸**：AOE=0 且敌 ≥3 → 不进精英。
- **换血闸**：花血换 relic/金币，先答「Act1 内回得了本吗」——+1 最大生命/场最多回 5–8 点，不值 14 点现血。

## 3. 每回合七步（写 batch 之前逐条对）

```
1 ANCHOR + HUD + 每只敌人意图 + POTIONS（有药先过四问）
2 一句「机制 + 意图循环」（MECHANICS/INTENT_MEM 只在变化时出现）
3 量斩杀：敌 HP + 格挡 + 胆小 ≤ 本回合总伤（★ 已含易伤/段数/荆棘；没 ★ 就自己算）
4 定回合类型：斩杀｜incoming≥HP 全挡/喝药｜≤10% 最大生命挡满｜否则吃满格挡池、净掉 ≤5
5 排序：0 费/抽牌/回费 → 易伤/虚弱/力量 → AOE → 单体收尾
6 一条 batch 出完（牌写 card_id，不写会变的手牌下标）
7 收尾三查（§1.3）
```

## 4. 数值与斩杀

```
单卡伤害 = 快照里的实时 Damage（已含力量/虚弱/遗物）
修正：易伤 ×1.5｜我虚弱 ×0.75｜我脆弱 格挡 ×0.75｜敌格挡先扣｜胆小首击 +6/7｜荆棘每段反伤
多段：每段独立吃格挡/胆小/荆棘（飞剑 3×3、双发 5×2 要乘段数）
```

- **AOE 清算**：AOE 总量 A vs 全场血 H。A≥H 清场（先易伤/降费/抽牌再一发收）；A<H 先收最危险的 1–2 只；N=1 别对单体放 AOE；召唤型敌人在召唤前留 AOE + 能量。
- **能量纪律**：结束 `energy` 必须 0，或逐张写明「不可打/零收益」；**0 费攻击必打**。
- **自伤四问**（放血/祭品/血墙/突破口）：这 2–6 血换的能量本回合能斩杀或挡 ≥ 自伤吗？HP ≤40% 不交；有别的回能就不交；交完下回合还够活吗？
- **状态牌**：感染/黏液 3 伤、呼唤 6 伤（无视格挡），全算进 incoming。
- **每费价值**：飞剑+ 12｜耸肩+ 11｜飞剑 9｜余烬 9｜上勾拳 6.5｜打击 6｜防御 5。

## 5. 血预算 / 药水 / SL

- **两回合账**：打完 H′、下回合入伤 I′，`H′ ≤ I′` → 这回合必须挡满或斩杀。
- **道中预算**：Act1 前 6 层 ≤5 血/场、整段 ≤20；Boss 前 ≥60%（理想 70%）；燃烧之血战后 +6。
- **药水四问**：解什么｜槽满留不留｜这回合会不会被打穿｜留给下场值不值。**交**：挡不住且净掉 ≥10% 最大生命｜斩杀差 5–15｜Boss 大攻击回合。**先核对单体/群体**——描述里「敌人」是单数就只作用一只。
- **Boss 战不省药**：进 Boss 就排「第几回合开哪瓶」，每回合问一遍「现在开能不能 0 伤 / 多打 20+ / 直接斩杀」，能就开；**打完还剩 ≥1 瓶 = 决策失误**。
- **调用必带目标**：`use_potion --option <槽> --target <敌下标>`（漏 target = `invalid_target`，别当成「药水无效」）。
- **SL**：只在「全挡/斩杀/喝药」全不成立时用；先答「这次哪一手不同」；常规战 ≤3 次，Boss 不占额度。流程 `save_and_quit` → 主菜单 `continue_run` → 重读快照（牌序可能重洗）。

## 6. 路线

`route` → `route --commit <opt> --note "…"` → 每节点 `plan` 对账（PLAN_OK / REPLAN）。

- commit 前扫「唯一出口是精英」；低血优先级：营火 > 问号 > 商店 > 怪 > 精英。
- REPLAN 触发：血线 <70%｜掉血 ≥20% 最大｜拿首张 AOE｜金币 100+｜牌组 +3｜多诅咒。
- **金币只有一个用途：删牌**；有诅咒时「交出全部金币换牌面变化」一律拒绝。

## 7. 构筑

| 指标 | 目标 | 红线 |
|---|---|---|
| 张数 | Act1 14–18，Act2 ≤22 | >24 抽不到组合；Act1 第 10 层起 18 张封顶 |
| 打击 | ≤3 | 4 张进 Act2 = 稀释 |
| 防御 | Act2 前 ≥6；精英前 8+ 甲 ≥2 张 | 单回合格挡 < 精英入伤 = 必输 |
| AOE | 1–2 张 | 0 AOE = 多怪磨死 |
| 收尾 | 1 张（重锤/契约终结） | 无收尾 = 打不死 Boss |
| 运转 | Act2 前 4 + 2 回费 | 只有一套启动 = 死 |

只补缺口：**AOE > 主轴核心 > 防御 > 运转 > 收尾**；≥14 张只拿 A 级。

## 8. 敌人

1. **召唤者**：本体 2 回合内能杀→直杀；否则先清爪牙（本体死爪牙撤）。
2. **荆棘/反伤**先叠甲再多段；**胆小/滑溜/无实体**用 AOE/多段破；**人工制品**先剥。
3. **Buff/Stun 回合不是安全回合**：按下一击留血线；成长型（力量/仪式）先杀。
4. **死亡召唤型精英**（寄生蛙/活雾/雾魔）杀前必答：这一手有 AOE + ≥3 能量吗？没有就压血到 15–25，等 AOE 收。
5. **紧缠/限费型**（蛇行扼杀者、缠结 +1 费、懒惰限 3 张）：当回合按最坏重算。

行级数据查 `references/enemies.md`（Boss 行必读，`read --offset/--limit` 只取那几行）。

## 9. 精英 / Boss

```
T ≈ 敌血 ÷ 实际 DPS        N ≈ 敌入伤 − 稳定可挡
T × N > 当前血量×0.6 → 不打
```

- **Act1 Boss**：199 血 ÷ 15–18 伤 = 11–13 回合，Boss 19–33 伤/回合；不够就别进。
- **Act2 Boss**：399 ÷ 25–35 = 12–16 回合 + 每 3 回合一枚 Debuff（少抽 1 / 限 3 张 / -1 费）→ 要 ≥100 血 + 20+ 甲/回合 + ≤22 张。
- **Boss 前**：HP ≥70%、2 张 8+ 甲、牌组 ≤18（Act2 ≤22）、金币 ≤20、药水先验过。
- **精英闸**：60% 血 + 2 张 8+ 甲 + 1 张 AOE + 1 瓶药（召唤型 70% + AOE 能量预算）。

## 13. 本季教训

1. **金币只有一种用法：删牌**（56）：诅咒在场时「全金币换变化」= 洗成诅咒 + 永远删不了牌。
2. **强制精英不看血闸**（56 第 12/14 层）：路线里唯一出口是精英，提前把血养到 60%。
3. **召唤型精英杀前一句**（54/56）：寄生蛙死召 4 只共 79 血；没 AOE+能量就压血等。
4. **状态牌是隐形血税**：感染/黏液 3、呼唤 6；56 局两回合空手 -21。
5. **Act1 第 10 层起 18 张封顶**：20 张 + 2 诅咒 = 连续空手。
6. **血换 relic 看回本**：+1 最大生命/场最多回 5–8，不值 14 现血。
7. **AOE 清场公式**：A≥H 才清场，A<H 收最危险的 1–2 只，N=1 不用 AOE。
8. **能量打空、0 费先打**：1 费躺手里 = 白丢 6–9 伤。
9. **自伤只在「本回合斩杀/挡 ≥ 自伤」时交**，HP ≤40% 不交。
10. **血量两件套**：狂宴（击杀 +4 最大生命）+ 黑暗之血（战后 +12），见到就拿。
11. **Boss 战不省药**（2026-10-26 用户口径）：药水是给 Boss 用的消耗品，不是存款。
