# 铁甲战士流派速查（v1，2026-10-25）

来源：知乎《杀戮尖塔2》战士测评:高胜率玩法分享（3-15）/ 17173《战士玩法及删牌思路》（漅汐）+ 易伤一刀流（9game/ali213）+ 本人 A10 习惯。卡名/数值以 `db/raw/cards.json` 为准。

## 1. 循环解（剑耸模型）

- 模型：**2 张抽牌 + 1 张加费**，互相抽打转起来；战士“缺抽不缺费”，抽牌优先于加费。
- 抽牌池：剑柄打击（9/10 伤+抽 1/2）、耸肩无视（8/11 甲+抽 1）、劫掠（6 伤+抽到非攻击）、怨恨（5 伤，掉血打 2 次）、燃烧契约（1 费定向烧+抽 2/3）、凶恶（给易伤抽 1）、杂耍（复制第三张攻击）。
- 加费池：放血（0 费 -3 血 +2/3）、被遗忘的仪式（1 费 +3 能，消耗）。
- 注意：**跃跃欲试不是加费**——3 费 15 甲 + 每点力量 +5 甲，是力量系格挡牌。
- 循环成型后是“公式化”的强，但**怕人工制品/脆弱怪**，别为了循环放弃短线。

## 2. 短线攻杀（道中清怪）

- 非金卡数值：愤怒、突破、完美打击、旋风斩、拆卸（对易伤打两次）、无情猛攻（14 伤，下一张攻击 0 费）、重锤、狱火（自残段数）、杂耍（0 费配合）。
- 打法：先易伤再打；对人工制品先剥制品；单卡质量优先，别堆低质攻击。
- 战士长线强、短线弱：短线要么攻杀速杀，要么防杀磨过，不要半攻半防。

## 3. 防杀（短线防御）

- 输出转防御：**狂怒**（0 费，本回合每打一张攻击获得格挡）——和“肚皮（全身撞击）是防御转输出”正好互补。
- 白卡三防：武装、耸肩、坚毅；蓝卡防：挑衅、邪眼、火焰屏障、重振；特殊防：无惧（消耗得甲）、巨像（易伤减伤）、绯红披风（长战）。
- 软肋：脆弱怪（被上脆弱后防御数值崩），优先留甲/解脆弱；对人工怪别指望易伤。

## 4. 易伤一刀流（本人主玩）

- 核心：**主宰**（1 费：给 1 易伤，敌人每层易伤 → 获得力量，消耗）+ **欺凌**（0 费：4 伤 + 每层易伤 +2）+ **残酷**（1 费：易伤敌人额外受 25%）。
- 过牌：**凶恶**（1 费：每次给易伤抽 1）。
- 易伤源：痛击（2 层）、挑衅（1 层+6/7 甲）、上勾拳（1 层+虚弱）、战栗（1 层+7 甲）、易伤药水。
- 防御：巨像（易伤敌人伤害 -50%）、岿然不动、火焰屏障。
- 打法：先叠 3–5 层易伤 → 主宰转力量 → 欺凌/高力量多段斩杀；人工制品先剥。

## 5. 删牌与路线

- 删牌：**先买卡/遗物，钱没处花再删**；看发牌——重振/地狱狂徒先来→删打击，狂怒/劫掠先来→删防御；无脑删打/删防都是错。
- 路线：战士短线弱、长线强 → **避精英、直取 Boss**，靠长线牌+药水混过；多营火敲牌（用户偏好，见 `route_pref_campfire_no_elite`）。

## 6. 与旧攻略的冲突

- **血墙**：Spire of Chaos 文推荐，但本人不抓；15+ 甲用岿然/火焰屏障/巨像（见 `blood_wall_not_core`）。
- **“用战损换发育”**：A10 只在能换掉成长怪/省更多血时换，否则先垫甲（荆棘先看甲）。
