# 药水与「小伤害必挡」· A10 铁甲实战细则

> 常驻部分在 `SKILL.md` §0.2 / §4；这里放细账、工具坑和反例，**决策前不必读全文，只在「有药水」或「入伤 7–14」时翻一眼**。

## 1. 药水四问（每回合看到 POTIONS 行就问一遍）

1. **它解什么**：挡伤 / 斩杀补 5–15 / 抽牌找运转 / 清虚弱脆弱 / 全体易伤 / 回血。
2. **不留会不会烂**：槽位只有 2 个（A4「收紧腰带」-1 之后仍是 2 格可装）。槽满再捡 = 必须先喝、先丢，否则新药水直接溢出。
3. **这回合会不会被打穿**：`incoming` vs `HP + 可挡`。差≥10% 最大生命 → 挡伤药水现在就是第三条路。
4. **留给下一场更值吗**：Boss 前一层留 1 瓶；营火前一格可以喝掉；精英 T1 血线 <60% 直接交。

## 2. 什么时候交（硬条件，满足一条就喝）

| 条件 | 用什么 |
|---|---|
| `incoming ≥ HP - 可挡`（这回合会死/濒死） | 挡伤/回血类，立刻 |
| `BLOCK_POOL 不够，净掉 N`，且 N ≥ 10% 最大生命 | 挡伤类 |
| 斩杀线差 5–15，且不斩杀下回合要掉 ≥15 | 攻击/力量/易伤类 |
| Boss 大攻击回合（20+）或你要启动的那回合 | 力量/敏捷/抽牌 |
| 精英 T1、血线 <60% | 任意挡伤/削弱 |

## 3. 什么时候留

- T1 满血、入伤 ≤10%：不喝。
- 下一格就是营火：喝掉比留着好（营火会回血，药水换血没意义）。
- Boss 前一层：留 1 瓶，但别留 2 瓶（另一瓶该在精英/恶战用掉）。
- 药水**不要**默认算进斩杀线；只有「入伤 ≥ HP」时它才算第三条路。

## 4. 工具用法与坑

```
python sts2.py state                     # 看 POTIONS 行（槽位号 + 药水名 + FX）
python sts2.py do use_potion --option 0                  # 不需要目标
python sts2.py do use_potion --option 1 --target 0       # 需要目标；不填会自动选最低血敌人
python sts2.py do discard_potion --option 0              # 槽满要先腾
```

- 返回 `pending`：**先重读 state**，看槽位是不是还在、`is_queued` 有没有变；**最多重试 1 次**（可带 target），还不动就换瓶或放弃，并在 thought 里说清楚——别把没生效的药水算进计划。
- 全敌药水（火焰/毒）在旧版本常不结算：用了就当场核对敌方 HP，没掉血就按「没生效」重算。
- 槽满拿新药水：先 `discard_potion` 丢掉最没用的那瓶，别让奖励卡在界面。

## 5. 反例：49 局两件事

1. **打 7 硬吃**：泥浆纺锤意图 `Attack 7;Buff`，我手里 2 张防御、3 点能量，却打 Inflame + 打击×2（18 伤）净吃 7。正确线：**打击 + 打击 + 防御**（12 伤 + 挡 5，净掉 2）。用户原话：「他打 7 的时候你可以先俩张打再起一次防，但是你硬吃伤害。」
   → 结论写进铁律 2：入伤 ≤10% 最大生命一律挡满，抢节奏不算理由。
2. **整局零药水**：49 局从头到尾 2 个槽都是空的，一次 `use_potion` 都没发。不是药水无效，是**根本没去拿/没去想**：商店优先买药水、事件给药水就拿、精英前补 1 瓶。
