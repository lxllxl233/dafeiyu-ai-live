# 第二/三幕路线图（A10 铁甲战士）

> 目前所有败局都在 Act 1；这个文档是为了“过 Act 1 之后不要迷路”。
> 重点不是背怪，而是：**牌组在 Act 2/3 要长成什么样，资源怎么花，Boss 前检查什么。**

## 1. 牌组最终形态（15–20 张）

进 Act 3 Boss 前目标：

- **4 张运转/抽牌**：Burning Pact / Pommel Strike / Battle Trance / Stoke / Dark Embrace
- **2 张回费**：Bloodletting / Forgotten Ritual / 能量药水不算牌
- **2–3 张优质防御**：Blood Wall / Flame Barrier / Shrug / Evil Eye / Impervious / Feel No Pain
- **1–2 张收尾**：Body Slam / Ashen Strike / Pact's End / Fiend Fire / 力量多段
- **1–2 张易伤/减益**：Bash / Uppercut / Shockwave / Taunt
- 基础 Strike/Defend：尽量 ≤3 张；多余的全删。

**不要**：Act 2 还在抓“过渡攻击”；三轴混抓；为了稀有攻击牌放弃删牌。

## 2. 第二幕：确认主轴，开始压缩

主要矛盾：从“活过 Act 1”变成“把牌组压到可循环”。

- **已确认主轴**：
  - 防御轴：Barricade + Body Slam + 高质量格挡；Juggernaut 可选。
  - 消耗轴：Corruption + Dark Embrace/Feel No Pain + Ashen Strike/Pact's End/Fiend Fire。
  - 力量轴：Demon Form/Inflame/Rupture + 多段（Whirlwind/Sword Boomerang）。
- **只拿增强主轴收尾的牌**；不要补第二套半成品。
- 商店：**删基础牌 > 关键引擎/防御 > 药水 > 遗物**；Boss 前把金币花掉。
- 营火：HP≥70% 且有关键升级（True Grit+/Body Slam+/Burning Pact+/Flame Barrier+）就锻造；低血睡觉。
- 精英：Act 2 精英战损高；HP<70% 默认绕；第一只可以打，第二只极慎重。

### Act 2 常见威胁（按 DB）

- 多怪/召唤：Fabricator、Fogmog、The Obscura、Ovicopter 等；**先杀召唤者本体**，爪牙随本体消失。
- 高攻/多段：Crusher、Doormaker、Kin Priest、Lagavulin Matriarch 等；每回合先算总 incoming。
- 状态/诅咒：优先用 Burning Pact/True Grit/Second Wind 烧掉；不要让手牌被塞满。
- 精英：Entomancer、Flail Knight、Infested Prism、Magi Knight、Mecha Knight、Phantasmal Gardener、Skulking Colony、Soul Nexus、Spectral Knight、Terror Eel 等；没有防御密度不碰。

## 3. 第三幕：锁牌与双 Boss

### Queen（400 HP）

- `Chains of Binding / 魂缚锁链`：**每回合前 3 张抽牌被 Bound**。
- `You Are Mine`：上 Frail/Vulnerable。
- `Barrier`：卡牌负面/防御；`Off with Your Head`/`Execution`：高伤攻击。
- 需求：
  - **4 运转 + 2 回费**，保证锁 3 张后还能启动；
  - 2–3 张优质防御，不能只靠一套格挡；
  - 1–2 张收尾，别把所有输出押在一张牌上；
  - 药水（抽牌/换牌/能量/格挡）留到锁牌后的启动回合。

### A10 双 Boss

- 两套独立启动能力；第一套打完，第二套还能转。
- 不要在第一个 Boss 把药水/关键能力全交；第二个 Boss 需要至少一次“重新启动”。
- 牌组 15–20 张；如果 >20，优先删基础牌/过渡牌，而不是继续加。

## 4. Act 2/3 抓牌优先级

| 类型 | 优先级 | 说明 |
|---|---|---|
| 引擎/消耗 | S | Corruption / Dark Embrace / Feel No Pain / Burning Pact / Second Wind |
| 回费 | S | Bloodletting / Forgotten Ritual |
| 优质防御 | A | Blood Wall / Flame Barrier / Shrug / Evil Eye / Impervious |
| 收尾 | A | Body Slam / Ashen Strike / Pact's End / Fiend Fire |
| 抽牌/运转 | A | Pommel / Battle Trance / Stoke / Dark Embrace |
| 过渡攻击 | C | 只在缺输出且马上要打精英/Boss 时拿 |
| 基础牌 | D | 不拿；优先删 |

## 5. Boss 前检查（Act 2/3 通用）

```
1. 牌组 ≤20？基础 Strike/Defend ≤3？
2. 4 运转 + 2 回费？（Queen 锁牌底线）
3. 2–3 张优质防御？每回合能不能挡住 Boss 的常规攻击？
4. 1–2 张收尾？不依赖单张牌。
5. 金币花掉了吗？药水够不够买一次启动？
6. 有没有“第二套启动”应对双 Boss？
7. HP≥70%？低血先营火。
```
