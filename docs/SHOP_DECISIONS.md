# 商店决策链路（A10 铁甲战士）

> 商店不是“有钱就花”，而是用金币买**接下来 3–5 场战斗的生存率**。
> 先定“现在最缺什么”，再决定买牌、删牌、药水还是跳过。

## 0. 先问四个问题

1. **接下来 3 场是什么？** 普通怪 / 精英 / 营火 / Boss？有没有双怪？
2. **我的 HP 是多少？** <50% 时，防御/药水权重高于“再买一张牌”。
3. **牌组多少张？** >16 张时，删牌优先；>18 张时，非关键牌默认不买。
4. **当前最缺什么？** AOE / 防御 / 烧牌引擎 / 回费 / 过牌 / 药水。只买解决第一缺口的牌。

## 1. 预算顺序（默认）

**删牌 > 关键防御/引擎/AOE > 药水 > 遗物**

但“关键”不是“看起来强”，而是：

- 能解决下一场/下一幕的主要矛盾；
- 能替代一张基础牌，或让下一次删牌更有价值；
- 符合当前主轴/收尾，不是三轴混抓；
- 接下来两幕都用得上。

## 2. 买牌五问（任何一张牌都要过）

1. 它解决我**现在**的主要矛盾吗？（AOE/防御/烧牌/回费）
2. 它比我将要删掉的那张基础牌强吗？
3. 它会不会让牌组变厚、降低关键牌抽取率？
4. 它符合我已确认的主轴/收尾吗？
5. 两幕内它还会在循环里吗？还是只是“这局看着还行”？

**五问有一问答不上来 → 跳过。** 跳过奖励/跳过购买是主动的强度选择。

## 3. 删牌

- **Act 1 早期**：优先删 **Strike**。1 费打 6 在 A10 前期不如 1 费防 5。
- **牌组成型（约 Act 2）**：转删 **Defend**；防御轴保留优质防御（Blood Wall/Flame Barrier/Shrug/Evil Eye）。
- **中后期**：删一切不服务“回费—运转—收尾”的牌。
- **不要删**：核心引擎（Corruption/Dark Embrace/Feel No Pain）、唯一收尾（Body Slam/Ashen Strike/Pact's End）、关键回费。
- 删牌前数一下：牌组 17+ 时，删牌是硬需求；15–16 时，按“最弱牌”删；≤14 时可以跳过删牌买关键牌。

## 4. 买药水

药水是“买一次额外启动/生存”，不是收藏品。

- **低血/下一场精英**：格挡药水、虚弱药水、技能药水（找防御）优先。
- **Boss 前**：抽牌/换牌/能量/复制药水优先。
- **药水槽满**：不买，除非确定替换；不要为了“便宜”塞满。
- **技能药水是盲盒**：可能给 Primal Force/Forgotten Ritual/Burning Pact 这类非防御牌；低血时不要把它当稳定格挡。

## 5. 组合价（bundle）要算总账

不要一件一件“感觉不贵”地买，最后变成“买了两张牌 + 一瓶药，没删牌”。

### 第 5 局实战：139 金，28 HP，牌组 14，缺 AOE/防御

商店：

- 闪电霹雳 49（AOE）
- 岩石铠甲 37（4 覆甲）
- 技能药水 49
- 删牌 100

可选方案：

| 方案 | 花费 | 结果 | 评价 |
|---|---:|---|---|
| A：删牌 100 + 岩石铠甲 37 | 137 | 牌组 14，删 1 张打击，+防御 | 最稳牌组质量；但没 AOE |
| B：闪电霹雳 49 + 岩石铠甲 37 | 86 | 牌组 16，+AOE+防御，剩 53 | 补两个缺口，保留 53 金；不删牌 |
| C：闪电霹雳 + 岩石铠甲 + 技能药水 | 135 | 牌组 16，+AOE+防御+药水，剩 4 | 第 5 局实际选择；**没删牌、牌组变厚、药水是盲盒** |
| D：删牌 100 + 闪电霹雳 49 | 149 | 超出 10 金 | 买不起 |

**第 5 局选了 C，是错的优先级**：在 28 HP、牌组 14 的情况下，应该选 **A 或 B**；技能药水是奢侈品，不该挤掉删牌/保留现金。C 让牌组 17（后续又加旋风斩），低血时抽不到防御。

## 6. 商店检查清单

```
1. HP 多少？<50% → 防御/药水优先，不买奢侈攻击。
2. 牌组多少？>16 → 先删牌；>18 → 非关键牌不买。
3. 最缺什么？AOE / 防御 / 烧牌 / 回费 / 过牌；只买第一缺口。
4. 买这张牌的五问，能过吗？
5. 总价多少？买完还剩多少？能不能“删牌 + 一张关键牌”而不是“两张牌 + 药水”？
6. 药水槽满吗？技能药水是盲盒，低血时别当稳定防御。
```

## 7. 连续商店与“购物清单”

连续进两次商店不是问题，**没有清单地逛**才是问题。

### 第 7 局案例

- 第一次商店：108 金，买了 **Burning Pact 燃烧契约 71**。
  - 可解释：1 费烧 1 抽 2，是消耗/运转核心。
  - 但在当时牌组里没有 **Feel No Pain/Dark Embrace** 这类消耗收益，也没有收尾；它只是“抽牌”，没解决 57 HP 下的防御/AOE。
  - 更稳的选择可能是：留钱等第二次商店/删牌，或买一张真正的防御。
- 第二次商店：剩 37 金，买了 **Armaments 武装 25**。
  - 这是典型的“便宜就买”：5 甲 + 升级，不是 A10 的优质防御；牌组已经 13 张，加它只稀释关键牌。
  - 正确：**不买，直接走**；25 金留着，后面商店/药水更有用。

### 进店前写四行

```
最缺：AOE / 防御 / 烧牌引擎 / 回费 / 药水
预算：最多花多少，留多少给后面
必买：明确 1–2 个牌名/类别
不买：便宜但不解决主要矛盾的牌
```

**如果第二次进店没有“必买”清单里的东西，直接离开。** 不要因为“都进来了”“才 25 块”就买。
