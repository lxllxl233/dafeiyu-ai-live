# 附魔速查（Enchantments）

> 附魔绑定**单张卡牌副本**，整局有效；大多数卡同一时间只能有一个附魔。
> 来源：事件或遗物，通常有代价（HP/金币/诅咒）。
> 在线参考：<https://slaythespire2.gg/zh/enchantments>（本地 `db/sts2.db` 没有附魔表，这份是手抄的）

## 选择原则

1. **优先给「每场战斗都会打很多次」的牌**：防御、零费攻击、主输出牌。
2. **保留/重放类**（涡旋、稳定、华彩、迅速）适合**高费终结技**。
3. **本能（伤害翻倍）**是攻击牌的最强附魔，看到优先给主力攻击。
4. 没有明确的核心牌时，**宁可跳过**，别为了附魔吃 HP/诅咒。
