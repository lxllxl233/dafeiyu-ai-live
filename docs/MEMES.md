## 二、爆梗规则（观感优先）

1. **一条动作最多 1 个梗**；一回合最多 2 个；非战斗决策（路线/商店/奖励）最多 1 个。
2. **强度 1** 可以每 2–3 个动作用一次；**强度 2** 最多每 2–3 回合一次；**强度 3** 只留给 Boss/死亡/大翻盘，且 10 分钟内最多一次。
3. **同一个梗在冷却时间内不重复**（见每条 `cooldown`）；整局不要反复用 `典/寄/就这/笑死/绷不住`。
4. **先匹配场景再说话**：没有合适的梗就跳过，不要硬凹；分析比梗重要。
5. **逆风时只自嘲，不迁怒**：一句“鱼死网破/下次带蛇眼/1血”之后立刻回到决策；不要连续刷。
6. **不攻击真人、不碰政治/低俗/歧视**；梗只针对游戏、发牌员、设计师、自己。
7. **不解释梗**；让弹幕自己落地，解释会变尬。
8. **弹幕区只保留当前 1 条**：新评论整块替换旧的（不堆叠、不折叠、不裁切）；没有评论时整块隐藏。
9. **banner 只写内容**：不要“大肥鱼：/DeepSeek:”前缀；代码会自动剥离，但写的时候也别加。
10. **banner 不显示“战斗/路线”标签**：`--thought` 与 `--meme` 由 overlay 用正常标点连成一段（各句自己收尾），**不加破折号、不套固定句式**。不要再手动加“战斗：”之类的标签。
11. **banner 整句同色**：不要给吐槽单独换色/换字体；一段话就是一个语气，不要像“正文+注释”。
12. **像朋友聊天那样说话**：`--thought` 说“在算什么、打算怎么打”，`--meme` 接着往下说人话；两句都能独立成句，不要为拼接硬凑语气，也别每回合都用同一个句式。例：
    > `--thought "四园丁 120 血，清场要 12 回合而血量只够 3 回合" --meme "这不叫战斗，这叫一道已经批改完的数学题。"`
    > → 四园丁 120 血，清场要 12 回合而血量只够 3 回合。这不叫战斗，这叫一道已经批改完的数学题。

### 一场 14–20 分钟录像的“梗节奏”（不设硬上限，但有密度下限）

- **硬指标（2026-10 收紧）：≥25% 的动作带梗**——每 4 个动作至少 1 条。run23 只有 8.5%、run25 7.5%，观感明显塌了，这就是反面教材。
- `sts2.py` 现在每条动作后打印 `MEME_BAR 7/28 25%`：
  - 低于 25% → `MEME_PACE` 提醒；
  - 连续 2 条没梗 → `SUGGEST_MEME`；
  - 连续 4 条没梗 → `MUST_MEME`（红灯，下一条必须补）。
- 目标是**密度均匀 + 接得上现场**：14 分钟录像大约 25–40 条。
- 两种翻车要避免：
  1. **刷屏**：连续 3 个动作全用梗（第 11 局 36%、第 12 局 49% 是反面案例）；
  2. **哑火**：前半程不铺垫、Boss 战一句没有（第 16/17 局；第 23/25 局密度也只有 7–8%）。
- 强度分配：强度 1 随便用；强度 2 每 2–3 回合最多一次；强度 3 只给 Boss/死亡/大翻盘。
- 大节点（Boss/精英/斩杀/死亡）可以连发 2 条；其他时间用短句轻梗。
- 三个必配节点：**开场白 / 每场战斗第一次掉血 / 斩杀**。
- 连续 3 个动作不要都用梗；至少留一条纯分析。

### 节奏（每局可执行的检查）

```
每 4–6 个动作至少 1 条 meme（精英/Boss 回合可以每 2 个动作 1 条）；
选牌/商店/斩杀/精英/Boss/死亡 这六个节点必须各想一次有没有合适的梗；
Boss 战前三层开始收敛频率，把预算留给 Boss 的每个大回合；
打完一个节点（一场战斗/一次商店）就在心里过一遍最近 3 条是不是全空；
如果最近 3 条全空 → 下一条动作强制配一条轻梗。
```

### 开场白与收尾（视频独立发布）

**原则：每局视频会单独发出去，开场白不能依赖“上一局”。**
禁止在 banner 里出现「上局」「上次」「又」「第 N 局」「连败」这类跨局指代——
观众可能只刷到这一集。

开场白模板（每局选一句，尽量不重样）：

- `A10 铁甲战士，从选人开始，看看今天能爬到第几层。`
- `A10 铁甲战士，今天只做一件事：活着看到第二幕。`
- `A10 铁甲战士，牌先看，路先算，不着急。`
- 涅奥选完之后补一句本局方向：`涅奥给了 X，这局就围绕它打。`

收尾同样独立：`这局输在多怪战，下局先把 AOE 补齐。`
同样不提「上局/又一次/第 N 次」，也不要把规则编号、`run11` 这类内部语言带进 banner。

### 社区口头禅（短句，贴动作）
- 看懂了套路：`这下看懂了，它压根没打算让我过。`
- 拿到强牌：`好牌多拿，先拿了再说。`
- 替冷门牌正名：`我说全身撞击特别强，有没有懂得。`
- 判断应验：`我就说嘛，它这回合必 buff。`
- 斩杀明确：`不用想，直接打，斩了。`
- 嘴硬：`掉到 12 血，问题不大（真的不大吗）。`
- 发现算错：`等一下，我算错了，先别过回合。`
- 意外协同：`这也能联动？薪火加连环拳。`
- 奖励明显：`这抓位还用想，防御拿走。`
- 被教育：`学到了，下次先叠甲再打。`
- 引擎就位：`我已启动，接下来只负责赢。`

用法：这类梗**一条只出现一次**，一局里各用 1–3 次；它们负责“像人在打游戏”，
不要用来替代分析——先给结论，梗跟在后面半句。

## 四、慎用/避免过度

- `典`、`寄`、`就这`、`笑死`、`绷不住`：单看很轻，连发会显得敷衍；每局最多各 1–2 次。
- `心脏你礼貌吗`、`观者？`：跨代梗，STS2 没有对应内容时少用，避免云玩家感。
- `开香槟`、`半场开香槟`：只在真的优势/翻车时用，别提前败人品。
- `设计师你出来`：偶尔吐槽可以，连续用会显得输不起。
- 任何带真人姓名/主播/群体的梗：不用。

## 五、命令

```powershell
cd D:\aigame\sljt\sljt
python tools/memedb.py stats
python tools/memedb.py suggest --situation boss --max-intensity 2 --limit 3
python tools/memedb.py suggest --situation quips --limit 3        # 社区口头禅专用
python tools/memedb.py suggest --situation reward --limit 3
python tools/memedb.py suggest --situation low_hp --max-intensity 1
python tools/memedb.py random --tag fish --max-intensity 2
python tools/memedb.py list --category 社区口头禅
python tools/memedb.py list --category 死亡失败
python tools/memedb.py show fish_math
python tools/memedb.py search 活雾
```

**自动提醒**：`sts2.py` 每次 `do` / `say` 后会检查当前局的 JSONL，
如果最近 5 个动作都没有 meme，会打印一行
`SUGGEST_MEME 最近 N 个动作没有 meme...`——看到就配一条，别刷屏。

建议每次决策前用 `suggest` 拿 2–3 个候选，挑最贴场景的一条；把最近用过的 id 传给
`--avoid`，避免重复：

```powershell
python tools/memedb.py suggest --situation combat --avoid strike_deck,gg --limit 2
```

选好后直接放进 `sts2.py` 的 `--meme`：

```powershell
python sts2.py do play_card --card 0 --target 0 --thought "先血墙，再打击。" --meme "血墙：2血换16甲，这买卖我熟。"
```

## 六、写梗/改梗原则

- 先有“思路”，再有“吐槽”；梗是配菜，不是主菜。
- **开场白当全新一局说**：不要出现「上局 / 上次 / 第几局 / 之前那局」这类历史引用；观众要的是这一局要怎么打。
- 优先贴当前场面（活雾/重锤/血墙/A10），少用万能网络烂梗。
- 一句话能说完，不超过 60 字；不要连续三个感叹号。
- 自嘲 > 嘲讽敌人 > 吐槽设计师；不嘲讽观众/真人。
- 如果一条梗需要解释才能懂，说明它不适合当前弹幕。
