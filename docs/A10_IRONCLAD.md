# A10 铁甲战士 · 战略框架（STS2 适配版）

> 来源：老板给的 A10 框架 + 本地 `sts2.db` 的 STS2 卡池/敌人数据 + 第 4 局实战校正。
> 这是“构筑链路”；每回合出牌见 `COMBAT_TURN.md`，开局见 `NEOW_DECISIONS.md`，第一幕实战见 `ACT1_PLAYBOOK.md`，二/三幕见 `ACT2_ACT3_PLAYBOOK.md`。
> 这不是“必须照抄的 tier list”，而是**否决顺序**：先保证不犯大错，再谈上限。

## 0. 一句话

**用消耗压缩牌库，用防御吸收 A10 的数值膨胀，用一条明确的收尾轴结束战斗。**
不要同时追三条轴；不要为了力量牺牲启动速度；不要带着半血和 200+ 金币进 Boss。

## 1. 三条不变量（先于任何抓牌）

### 1.1 血量是最高优先级战略资源

- 铁甲战士初始遗物 **Burning Blood / 燃烧之血**：每场战斗后回复 **6 HP**。A10 下这 6 点被放大，因为它决定你能不能“打完还能打下一场”。
- A10 开局 **64/80**；道中尽量维持 **≥70%**（约 56+）。低于 70% 时，**火堆优先睡觉**，不要贪敲。
- A10 精英战损极高：**第一只精英可以打，第二只必须极度慎重**；“第一只轻松过”不代表第二只不会把你打残。
- 一切“以血换收益”的牌/决策都要加警惕权重：  - **Blood Wall**（-2 HP 换 16 甲）、**Offering**（-6 HP 换 2 能量+抽3）、**Breakthrough**（-1 HP 打9 AoE）、**Brand**（-1 HP 烧1 +1力量）、**Inferno**（每回合 -1 HP 打6 AoE）、**Crimson Mantle**（每回合 -1 HP 得8甲）、**Rupture**（掉血换力量）。
  - 这些牌不是不能抓，而是**不能在没有回血/格挡兜底时裸抓**。

**否决规则**：如果当前 HP < 50%，跳过所有“自伤换成长”的牌，除非它立刻解决本场生存。

**火堆不是默认睡觉**：HP≥70% 且有关键升级目标时锻造；满血睡觉=浪费发育。升级优先级和“不要连敲两张打击”见 `docs/CAMPFIRE_UPGRADES.md`。

### 1.2 烧牌/消耗是最高抓位规则

无论最终走力量、防御还是混合，**消耗/烧牌牌的抓取优先级无条件排在第一位**。原因不是“消耗流最强”，而是：

- 消耗把牌库压缩到可循环的状态；
- 压缩后，关键牌（回费、运转、收尾）的抽取概率才够；
- A10 的数值膨胀需要“每回合稳定做同一件事”，而不是“每局都抽到不同的半套牌”。

**STS2 铁甲战士的消耗核心（本地 DB 校正）**：

| 牌 | 费/类型 | 效果 | 定位 |
|---|---|---|---|
| **Corruption 腐化** | 3 / Power / Ancient | 技能牌费用变 0；每次打出技能牌消耗 | 大烧核心，启动后技能免费 |
| **Dark Embrace 黑暗之拥** | 2 / Power / Rare | 每当一张牌被消耗，抽 1 | 消耗引擎，补牌 |
| **Feel No Pain 无惧疼痛** | 1 / Power / Uncommon | 每当一张牌被消耗，获得 3 格挡 | 消耗引擎，防御 |
| **Burning Pact 燃烧契约** | 1 / Skill / Uncommon | 消耗 1 张牌，抽 2 | 单烧+运转，职业核心 |
| **Second Wind 重振精神** | 1 / Skill / Uncommon | 消耗手中所有非攻击牌，每张得 5 甲 | 防御+大烧 |
| **Fiend Fire 恶魔之焰** | 2 / Attack / Rare | 消耗整手牌，每张造成 7 伤害 | 收尾/大烧 |
| **Ashen Strike 灰烬打击** | 1 / Attack / Uncommon | 9 伤，每张消耗牌 +3 | 消耗收尾 |
| **Pact's End 契约终结** | 0 / Attack / Rare | 消耗堆≥3 时，对全体 17 | 消耗 AOE 收尾 |
| **Brand 烙印** | 0 / Skill / Rare | -1 HP，消耗 1 张，+1 力量 | 烧牌+力量过渡 |
| **Stoke 添柴** | 1 / Skill / Rare | 消耗整手牌，每张抽 1 | 大烧/换手 |
| **Havoc 破灭** | 1 / Skill / Common | 打出抽牌堆顶牌并消耗 | 单烧，可拿 2 张 |
| **True Grit 坚毅** | 1 / Skill / Common | 7 甲，随机消耗 1 张 | 防御+单烧（随机，慎用） |
| **Cinder 余烬** | 2 / Attack / Common | 17 伤，消耗抽牌堆顶 | 输出+单烧 |
| **Drum of Battle 战鼓** | 1 / Skill / Uncommon | 抽 2；每回合开始消耗抽牌堆顶 | 运转+单烧 |

**否决规则**：奖励同时出现“优质力量牌”和“普通但可用的烧牌”时，A10 默认选烧牌，除非你当前已经因为缺输出而濒临死亡。

### 1.3 卡组规模目标是 15–20 张

- 第一幕结束：**12–15 张**；最终：**15–20 张**。
- 目标结构：**回费 2 + 运转 4 + 防御 2–3 + 收尾 1–2**，其余为过渡。
- **每一次跳过奖励都是主动的强度选择**：不服务于压缩循环或当前生存的牌，跳过它是在保护牌库纯度。
- 第三幕 Queen 的 **Chains of Binding / 魂缚锁链**：每回合抽到的**前 3 张牌被侵蚀为魂缚（Bound）**。所以不能只靠一套启动；至少 **4 张运转 + 2 张回费**，保证锁牌后仍有可打牌。
- A10 双 Boss 需要两套独立启动能力；药水（抽牌/换牌/烧牌/格挡）在这个窗口是“买一次额外启动”的战略资源。

## 2. 阶段化抓牌链路

### 窗口 1：第一幕前期——先站住

**主要矛盾**：活过第一幕的强怪池和第一只精英，不追梦。

优先抓取：

1. **1–2 张优质对单输出**：解决高压单体（如 Cinder、Bash、Uppercut、Pommel Strike）。
2. **2 张 AOE**：STS2 群怪密度高，AOE 优先级远高于一代。可用：
   - **Whirlwind 旋风斩**（X 费，5 伤×X 对全体）
   - **Breakthrough 突破**（1 费，-1 HP，9 伤对全体）
   - **Conflagration 焚烧**（1 费，10 伤对全体，本回合每打一张攻击 +2）
   - **Inferno 狱火**（1 费 Power，每回合 -1 HP，掉血时 6 伤对全体）
   - **Thunderclap 闪电霹雳**（1 费，4 伤+1 易伤对全体）
   - **Pact's End 契约终结**（0 费，3 张消耗后 17 对全体）
3. **1 张稳定易伤**：Bash / Uppercut / Taunt / Shockwave；易伤是前中期增伤引擎。
4. **优质防御**：Blood Wall / Shrug It Off / Flame Barrier / Evil Eye / True Grit；A10 的防御容错要提前建立。
   - **低血时 Flame Barrier/Shrug 优先于 Blood Wall**：9 HP/13 攻时，Flame Barrier+ 是 12 甲+反伤4（9→8 HP，反伤4），Blood Wall 是 16 甲-2 HP（9→7 HP，无反伤）；不要只看 16>12。
5. **过渡牌**：Armaments（武装）、Evil Eye（邪眼）、Battle Trance（战斗专注）、Pommel Strike（剑柄打击）等。它们不一定是最终组件，但让你活到最终组件。

**第一幕精英**：最好打一只拿遗物；第二只必须极慎重。如果 HP < 70%，直接绕。

### 窗口 2：第一幕中后期到第二幕——确认主轴，开始压缩

当你有基本输出、防御、1 张易伤后，抓牌逻辑切换到 **“确认主轴 + 开始烧牌”**。

三条主轴的出现信号：

| 主轴 | 信号牌 | 收尾 | A10 评价 |
|---|---|---|---|
| **力量轴** | Demon Form / Inflame / Rupture + 多段攻击（Whirlwind、Sword Boomerang） | 多段攻击、力量堆高 | 最稳定但启动慢；3 费引擎裸抓容易死 |
| **防御轴** | Barricade / 高质量格挡 + Body Slam / Juggernaut | Body Slam（伤害=格挡）、Juggernaut | A10 容错最高；但 Barricade 3 费会卡手 |
| **消耗轴** | Corruption / Burning Pact + Dark Embrace / Feel No Pain | Ashen Strike / Pact's End / Fiend Fire | 上限最高；没有收尾会“烧得很爽但打不死人” |

**关键决策点**：不要三条轴都追。选择判据是“你最早拿到的、能定义收尾方式的牌”：

- 先来 **Barricade + Body Slam** → 防御轴；
- 先来 **Demon Form + 多段攻击** → 力量轴；
- 先来 **Corruption + Dark Embrace/Feel No Pain** → 消耗轴。

其余轴线的牌只在“能直接增强主轴收尾”时抓。

### 窗口 3：第二幕到第三幕——小循环工程学

核心问题从“抓什么”变成“烧掉什么、留下什么、循环怎么闭合”。

目标状态：牌库只剩 **回费 + 运转 + 收尾** 三层。

- **回费核心**：Bloodletting（放血，0 费 -3 HP 得 2 能量）最高优先；Forgotten Ritual（被遗忘的仪式，消耗过牌则得能量）看稳定性。
- **运转核心**：Burning Pact（燃烧契约，几乎可以说是战士核心）、Pommel Strike（剑柄打击）、Battle Trance（战斗专注）、Stoke（添柴）。
- **收尾核心**：
  - 防御轴：Body Slam（全身撞击）+ Barricade（壁垒）/ Juggernaut（势不可当）
  - 消耗轴：Ashen Strike（灰烬打击）/ Pact's End（契约终结）/ Fiend Fire（恶魔之焰）
  - 力量轴：Whirlwind（旋风斩）/ Sword Boomerang（飞剑回旋镖）/ 多段攻击
- **单烧 3–4 张**：Burning Pact / Havoc（破灭，可拿 2）/ True Grit / Cinder / Brand。
- **Rage 狂怒**：0 费，本回合每打一张攻击得 3 甲；在大量删防御的 A10 环境里能显著减少战损，但很吃升级（升级后 5 甲/攻击）。
- **注意**：不要为了“烧而烧”把收尾也烧了；Fiend Fire/Stoke 前先确认手牌里没有唯一收尾。

### 窗口 4：第三幕 Boss 前——检查锁牌对冲

- Queen 400 HP；**魂缚锁链**：每回合前 3 张抽牌被 Bound。
- 底线：**4 运转 + 2 回费**；如果运转牌里有“消耗后抽牌”类型，要确保锁牌后仍能启动。
- 药水：抽牌药、换牌药、烧牌药、格挡药都能“买”一次额外启动；Boss 前不要省。
- 双 Boss：两套独立启动；不要把全部希望押在一张 Corruption 上。

## 3. 力量、防御、消耗的交叉决策

**消耗是底层引擎，力量/防御是收尾方式。** 用 AI 的话说：消耗决定状态空间能否被压缩到可解；力量/防御决定压缩后用什么动作终结。

| 场景 | A10 倾向 | 理由 |
|---|---|---|
| 烧牌 vs 力量引擎 | **烧牌** | 启动速度优先于成长上限 |
| 防御牌 vs 第二张力量牌 | 防御轴选防御；力量轴且防御已够才选力量 | A10 默认防御容错，战损是最大 run-killer |
| Body Slam vs 重刃/多段 | 防御轴选 Body Slam；力量轴选多段 | 不要混搭收尾：Body Slam 吃格挡，力量收尾吃力量 |
| Feel No Pain vs Inflame | **Feel No Pain** | 消耗触发格挡直接减战损；Inflame 的成长在 A10 启动压力下经常来不及 |
| Corruption vs Demon Form | **Corruption** | 优先“消耗标签”的引擎，而非单纯力量加成 |
| 第二只精英 | 默认绕 | 第一只轻松≠第二只安全 |

**力量轴注意**：Demon Form 3 费，打出当回合无效果；没有防御兜底不要裸抓。Rupture/自伤配合需要回血或格挡。
**防御轴注意**：Barricade 3 费，启动回合可能卡手；需要回费或 0 费防御（Rage）铺垫。Body Slam 是收尾，不是防御牌。
**消耗轴注意**：没有 Ashen Strike / Pact's End / Fiend Fire / Body Slam 这类收尾时，纯烧牌会陷入“烧得很爽但打不死人”。

## 4. 删牌链路（按时间轴）

> 商店的买牌/删牌/药水/组合总账见 `docs/SHOP_DECISIONS.md`；这里只放删牌曲线。

删牌不是“先删打击再删防御”的死口诀，而是**当前牌库最拖累循环的牌**。

1. **第一幕早期**：优先删 **Strike**。1 费打 6 在 A10 前期不如 1 费防 5；防御牌的实际价值更高。
2. **牌库开始成型（约第二幕）**：转向删 **Defend**。基础防御在压缩后是纯废牌；但防御轴保留优质防御（Blood Wall/Shrug/Flame Barrier/Evil Eye）。
3. **中后期**：删除一切不服务于“回费—运转—收尾”的牌，包括早期过渡攻击、多余基础防御、与主轴无关的“看起来还行”。
4. **商店优先级**：**删牌 > 买关键卡 > 药水 > 遗物**。后置商店集中删基础牌。
5. **例外**：
   - 防御轴：防御删除优先级后移，优先删打击；
   - 力量轴且防御端极薄：可激进删防御追求循环，但要有 Rage/Feel No Pain 等局内格挡兜底。

## 5. 微观战斗决策（AI 可执行）

1. **能斩杀时**：先算斩杀线，不要多打一张无意义的防御。
2. **不能斩杀时**：先满足本回合生存下限（格挡 ≥ 总伤害），再考虑成长/过牌。
3. **生存有保障时**：优先打消耗牌，压缩牌库本身就是收益。
4. **多敌人**：AOE 优先于单点；Whirlwind/Breakthrough/Conflagration/Thunderclap 是常规循环。
5. **易伤**：在爆发回合前施加，而不是“有了就打”。
6. **True Grit**：手里有关键防御/收尾时不要先打；随机消耗可能把 Defend/Body Slam 扔掉（第 4 局教训）。
7. **Ringing / Smoggy**：只允许 1 张牌/1 张技能时，先选“能活/能杀”的那一张，不要按常规顺序。
8. **召唤者**：优先本体；爪牙随召唤者死亡消失（活雾/Gas Bomb）。
9. **Boss 前**：确认金币花掉、药水可用、格挡牌数量够；不要带着 200+ 金币进 Boss（第 4 局教训）。

## 6. 一页检查清单

每次决策按顺序过：

1. **血量安全吗？** 低于 70%？→ 路线提高火堆权重，睡觉优先于敲牌。
2. **这张牌是烧牌/运转/回费吗？** 是 → 极高概率抓。
3. **它直接解决当前阶段主要矛盾吗？** 第一幕看输出/AOE/防御；第二幕看主轴确认；第三幕看锁牌对冲。
4. **它让牌库更薄/更可循环吗？** 会变厚但不增强循环 → 跳过。
5. **删牌时，当前最拖累循环的是打击还是防御？** 按实际牌库删，不按固定口诀。

## 7. STS2 关键校正（和一代不同的地方）

- **Heavy Blade / Immolate 等一代牌在本地 DB 中不存在**；不要按一代记忆抓牌，抓前查 `python tools/gamedb.py card <名字>`。
- **Queen**：400 HP；`Chains of Binding / 魂缚锁链` 使每回合前 3 张抽牌变 Bound；`You Are Mine` 上 Frail/Vulnerable；`Off with Your Head`/`Execution` 是高伤攻击。锁牌对启动要求极高。
- **Ceremonial Beast**：262 HP（A10）；HP 降到 160 触发 `Plow` 眩晕；有 `Ringing`（每回合只能 1 张牌）阶段。第 4 局就是在这里 3 HP 被 19 点收掉。
- **A10 开局 64/80**；Burning Blood 战后 +6；第 4 局进 Boss 87 HP 但仍被 262 HP 的 Boss 磨死，说明**防御密度比“进 Boss 血量”更重要**。
- **第 4 局教训**：4 Defend + 1 True Grit 的防御密度不够；True Grit 随机消耗扔掉了 Defend/Body Slam；233 金币没花出去。下一局把“Boss 前商店/血墙/Shrug/Flame Barrier”设为硬条件。

## 8. 下一局执行模板

```
开局：A10 铁甲战士；Neow 优先给资源/路线灵活性；地图先 route。
Act 1 前期：2 单点 + 2 AOE + 1 易伤 + 2 防御；最多 1 精英；商店删 Strike。
Act 1 后期：确认主轴；开始拿 2–3 张烧牌/运转；牌组 12–15。
Act 2：补 2 回费 + 4 运转；防御轴补 Blood Wall/Shrug/Flame Barrier；力量轴补多段；消耗轴补收尾。

```
