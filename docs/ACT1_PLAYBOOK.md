# 第一幕实战手册（A10 铁甲战士）

> 前 7 局有 6 局死在第一幕。这个文档只解决一件事：**怎么稳定过 Act 1**。
> 构筑/出牌/商店/篝火/Neow 的通用规则见对应文档；这里给“这一场怎么打”。

## 1. 第一幕牌组目标（12–15 张）

进 Boss 前理想结构：

- **2 张 AOE**：Whirlwind / Thunderclap / Breakthrough / Conflagration / Pact's End
- **1–2 张易伤**：Bash / Uppercut / Taunt / Shockwave
- **2–3 张优质防御**：Blood Wall / Flame Barrier / Shrug / Evil Eye / Impervious
- **1–2 张运转/回费**：Burning Pact / Pommel / Battle Trance / Bloodletting
- **1 张收尾**：Body Slam / Ashen Strike / Fiend Fire / Bash+
- 基础 Strike/Defend 尽量 ≤4 张；牌组 >16 时，非关键牌默认跳过。

**不要**：3 费引擎裸抓（Demon Form/Barricade）没有防御兜底；第二张精英；在 50% HP 以下连打两场。

## 2. 第一幕普通怪：意图与打法

| 敌人 | HP | 关键点 | 打法 |

| **Nibbit 小啃兽** | 42–46 | 叠力量、攻击+防御、Buff | 尽早杀；它越拖越疼；攻击后可能防御，斩杀线要算格挡 |

### 多怪通用

- 先看**总 incoming**，不是看第一只。
- 优先杀“攻击/叠力量/召唤”的单位；Buff/Status 单位可以后处理。
- AOE 不是“有就用”：如果 AOE 不能改变斩杀/减少攻击频率，先单点杀攻击单位。
- 有 Thorns 的怪：不要用 0 费多段/小攻击硬撞；用大单发或先杀别的。

## 3. 第一幕精英

**政策：最多 1 只；第二只默认绕。** 进精英前 HP≥70%，且手里有至少 2 张防御/1 张易伤。

| 精英 | HP | 关键点 | 打法 |
|---|---:|---|---|
| **Bygone Effigy 旧日雕像** | 127 | Slow：每打一张牌，本回合受到攻击伤害 +10% | 先打防御/低费牌叠 Slow，再集中攻击；不要一上来把高费攻击打完 |
| **Byrdonis 多尼斯异鸟** | 81–84 | 每回合结束 +1 力量；多段 | 尽早杀；每回合算多段总伤，格挡要够 |
| **Phrog Parasite 异蛙寄生虫** | 61–64 | 死亡时召唤；感染/甩动 | 要么快速斩杀本体，要么准备好 AOE 清召唤物；低血不碰 |

## 4. 第一幕 Boss：Ceremonial Beast 仪式兽

- **262 HP（A10）**；`Plow`：HP 第一次降到 **150/160 左右**会眩晕；`Ringing`：某些回合只能打 **1 张牌**。
- 进 Boss 前检查：HP≥70%、至少 2 张优质防御、1 张易伤、药水可用、金币花掉、牌组≤15。
- 回合计划：
  1. 先算 incoming；Ringing 回合只打“能活/能杀”的 1 张。
  2. 把 Boss 打到 160 触发眩晕；眩晕回合用来铺引擎/防御/输出。
  3. 不要在 Ringing 回合先打 True Grit/随机消耗；关键防御/收尾会被扔掉。
  4. Body Slam 在格挡后打；易伤在爆发前上。
  5. 药水留到 Ringing/斩杀/低血，不要省到死。
- 失败案例：第 4 局 87 HP 进 Boss，防御密度不够，被磨到 3 HP；说明“进 Boss 血量”不等于“能过 Boss”，**防御牌数量**才是关键。

## 5. 第一幕奖励/事件/问号

### 卡牌奖励五问

1. 它解决 Act 1 当前主要矛盾吗？（AOE/防御/易伤/运转）
2. 它比我将要删的基础牌强吗？
3. 它让牌组超过 15 张了吗？
4. 它符合我已确认的主轴吗？
5. 两幕内它还会在循环里吗？

**答不上就跳过。** 跳过一次奖励，比塞一张“看起来还行”的牌更值。

**默认动作是跳过，不是拿牌。** 第 10 局 6 次奖励 0 次跳过，牌组 11→18，Boss 关键回合抽不到格挡牌。执行方法：

- 进 Act 1 先写“缺口清单”（AOE / 易伤 / 防御 / 运转 / 收尾），只有**填空缺口**的牌才拿；同类第二张要看是不是质变。
- 牌组 ≥14：只拿 A 级（引擎/收尾/优质防御）；≥16：只拿能立刻改变 Boss 战的牌。
- **防御牌不超过牌组 1/3**，2 费纯格挡大牌（Blood Wall）最多 2 张；再多就先补输出。
- 防御必须能变现：没有 Body Slam/Barricade/Feel No Pain/足够力量的防御只是拖延，Boss 199 血会把你磨死。

### 事件

- 先比较：HP 成本 / 最大 HP / 金币 / 诅咒 / 变化/删牌。
- **永恒诅咒**（如 Greed）不拿；普通诅咒可在商店删。
- 低血（<50%）不接“掉血换资源”的事件；除非下一格就是营火。
- 变化 2 张基础牌 > 删 1 张（有商店时），见 `NEOW_DECISIONS.md`。

### 问号

- HP<50% 时问号有战斗风险；能走营火/商店就不要赌问号。
- 问号前先看路线：如果问号后面没有营火，低血不赌。

## 6. 第一幕路线检查

- 开局 `route`：优先 **营火/商店/Boss 前营火**；精英≤1。
- HP<70%：火堆权重提高；HP<50%：下一格必须营火。
- Boss 前 3 层内最好有商店；没有就留钱/改道。
- 不要连续打两场以上再找营火；A10 的战损是复利。
