# 篝火决策：睡觉还是锻造（A10 铁甲战士）

> 篝火不是“默认睡觉”，也不是“有升级就敲”。
> 它是一次**用当前 HP 换未来战力**的决策：先看血线、下一场、牌组里有没有值得投资的牌。

## 0. 先问三个问题

1. **现在 HP 多少？** 低于 60% 时，睡觉的生存价值通常高于一次升级。
2. **下一场是什么？** 精英/Boss 前，血线阈值提高；普通怪/问号前，可以更激进锻造。
3. **牌组里有没有“升级后质变”的牌？** 没有就睡觉，不要为了敲而敲。

## 1. 睡觉 vs 锻造（默认阈值）

| HP | 下一场 | 默认选择 |
|---|---|---|
| <50% | 任何 | **睡觉**；除非升级能立刻解决下一场（很少） |
| 50–70% | 精英/Boss | **睡觉**，把血线拉到 70%+ |
| 50–70% | 普通怪/问号 | 可锻造，但只敲“质变牌”；否则睡觉 |
| 70–85% | 普通怪/问号 | **锻造**，优先质变牌 |
| 70–85% | 精英/Boss | 看牌组：有质变牌且血线够挡第一轮 → 锻造；否则睡觉 |
| ≥85% / 满血 | 任何 | **锻造**，睡觉会溢出，价值低 |

**A10 补充**：Burning Blood 战后 +6，但半血进精英/Boss 仍可能被秒；血线阈值比低难度更高。

## 2. 升级优先级（按“质变程度”，不是按稀有度）

### S 级：升级后机制/费用变化，优先敲

| 牌 | 升级效果 | 为什么优先 |
|---|---|---|
| **True Grit 坚毅** | 7→9 甲；**随机消耗 → 选择消耗** | 直接修复“随机扔掉 Defend/Body Slam”的问题；有 True Grit 时优先敲 |
| **Body Slam 全身撞击** | 1 费 → **0 费** | 防御轴收尾质变；0 费让每回合都能撞 |
| **Burning Pact 燃烧契约** | 抽 2 → **抽 3** | 运转核心，直接多一张手牌 |
| **Pommel Strike 剑柄打击** | 9→10 伤；抽 1 → **抽 2** | 攻防一体的过牌 |
| **Cinder 余烬** | 18→**24** 伤 | 斩杀线质变，精英/Boss 更稳 |
| **Flame Barrier 火焰屏障** | 12→16 甲，反伤提高 | 低血/多段防御质变 |
| **Blood Wall 血墙** | 16→20 甲 | 防御密度提升；但低血仍要先看自伤 |
| **Shrug It Off 耸肩** | 8→11 甲 | 附带抽牌，防御效率高 |
| **Evil Eye 邪眼** | 8/8 → 11/11 甲 | 消耗流防御质变 |
| **Stone Armor 岩石铠甲** | 4→6 覆甲 | 每回合多 2 甲，长线防御 |
| **Feel No Pain 无惧疼痛** | 3→4 甲/消耗 | 消耗引擎，防御密度提升 |
| **Pact's End 契约终结** | 18→24 AOE | 消耗轴清场质变 |
| **Fiend Fire 恶魔之焰** | 7→10/张 | 消耗收尾质变 |
| **Demon Form 恶魔形态** | +3→+4 力量/回合 | 力量轴质变 |
| **Second Wind 重振精神** | 5→7 甲/张 | 防御+大烧质变 |
| **Uppercut 上勾拳** | 1/1 → 2/2 虚弱/易伤 | 减益质变 |
| **Battle Trance 战斗专注** | 抽 3→4 | 过牌质变，但仍要最后打 |

> 费用降低类（Corruption+/Dark Embrace+/Barricade+ 等）如果能降费，启动回合质变；以游戏内升级描述为准，优先于普通数值升级。

### A 级：关键攻击/易伤，视牌组敲

- **Bash+**：8→10 伤，易伤层数不变（以游戏内为准）；如果它是你唯一易伤且后续多攻击，可敲。
- **Twin Strike+ / Headbutt+ / Iron Wave+**：数值/防御提升，但没有质变；缺输出时才考虑。
- **Armaments+**：若升级后能升级整手牌，价值高；否则只是 5 甲+单升级。

### B 级：基础打击/防御，默认不敲

- **Strike+**：6→9 伤；**Defend+**：5→8 甲。
- 它们是你**优先要删的牌**；升级它们等于把资源投在将被移除的牌上。
- 只有在“没有更好的升级目标 + 这张牌暂时不会删 + 正好跨过斩杀/格挡阈值”时才敲；**不要连续敲两张打击**。
- 如果你发现篝火只能敲 Strike/Defend，说明牌组缺少值得投资的引擎/防御/收尾——睡觉保血线通常更好。

## 3. 升级 vs 删牌：不要投资将被删的牌

- 升级前先看牌组：这张牌在最终 15–20 张里吗？会被删吗？
- **Strike/Defend 是删牌对象**；给它们升级，和“压缩牌库”的方向相反。
- 优先升级“会留到最终循环”的牌：引擎（Corruption/Dark Embrace/Feel No Pain）、收尾（Body Slam/Ashen Strike/Pact's End/Fiend Fire）、高质量防御（Flame Barrier/Blood Wall/Shrug/Evil Eye/True Grit）、回费/运转（Burning Pact/Pommel/Bloodletting）。

## 4. 常见错误

1. **默认睡觉**：HP 80/80 还睡，等于浪费一次升级；A10 的数值膨胀需要升级来对冲。
2. **有升级就敲**：连续敲 Strike/Defend，牌组没变强，还挤掉了关键升级。
3. **不看下一场**：下一格精英/Boss，血线 50% 还锻造，进去被秒。
4. **升级将被删的牌**：Strike+ 再强，也不如把 Strike 删掉、把升级给 Cinder/True Grit。
5. **True Grit 不升级**：随机消耗是第 4/5 局的直接死因之一；有 True Grit 时，True Grit+ 的优先级很高。

## 5. 一页检查清单

```
1. HP 多少？<50% → 睡觉；50–70% 看下一场；≥70% 可锻造。
2. 下一场是精英/Boss 吗？是 → 血线阈值提高到 70–75%。
3. 牌组里有没有 S 级质变牌？有 → 锻造它。
4. 只有 Strike/Defend 可敲吗？是 → 睡觉，别投资将被删的牌。
5. 这张牌会留到最终 15–20 张吗？不会 → 不敲。
```
