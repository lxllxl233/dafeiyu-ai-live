# A10 铁甲战士 · 每回合出牌链路（STS2 实战版）

> 抓牌是在**构造**一个可解的状态空间；出牌是在这个已经被压缩过的空间里，找**当前约束下的最优动作**。
> 这两套链路必须分开：抓牌看“未来能不能循环”，出牌看“这一回合怎么不死、怎么把窗口延长”。

## 0. 每回合固定流程（顺序不能变）

1. **读 `MECHANICS`**：state 里自动列出的敌人被动，决定目标与出牌方式（打空格挡会眩晕？被挡满会眩晕？每回合第一次命中给格挡？见 `docs/ENEMIES.md`）。
2. **读 `RELIC FX` / `POTION FX`**：手上遗物和药水的中文效果（每回合都自动打印），确认这战能用什么。
3. **读 ANCHOR**：敌人数、incoming 总值、能量、手牌数。
4. **算这回合会不会死**：incoming ≥ 当前 HP 就必须挡满或斩杀。
5. **决定这回合的角色**：挡满 / 换血输出 / 铺垫引擎。
6. **按牌序执行**：能力 → 易伤 → AOE → 收尾（见 §4）。

两套链路的分工

| 链路 | 问题 | 时间尺度 | 失败方式 |
|---|---|---|---|
| 抓牌/构筑 | 这套牌能不能在 3 幕内形成可循环的解？ | 整局 | 牌组太厚、三轴混抓、没有收尾 |
| 出牌/战斗 | 当前约束下，这一回合的最优动作是什么？ | 一回合 | 贪成长、算漏斩杀、乱烧关键牌、牌序错 |

**出牌链路的目标函数不是“最高伤害”，而是“在不消耗未来的前提下，度过眼前的节奏点”。**

## 1. 第 0 层：态势锚定（先看敌人，不看手牌）

每回合开始，先花两秒回答：

1. **敌人这回合的意图是什么？**
   - 单次高额攻击 / 多段攻击 / Buff / Defuff / 防御 / 召唤 / 眩晕。
   - 读取 `/state` 的 `intents`：优先用 `total_damage`，没有就 `damage × hits`。
   - 多敌人要**逐个加总**，不要只看第一个。
2. **我离“翻盘点”还有多远？**
   - 这是走廊战、精英战还是 Boss 战？
   - 核心引擎（Corruption / Dark Embrace / Feel No Pain / Demon Form / Barricade）是否已经打出？
   - 如果还没打出：这一回合要在“生存”和“启动”之间明确分配权重。
3. **斩杀线在哪里？**
   - 敌人剩余 HP、我的攻击牌、能量、力量/易伤/虚弱、敌人格挡/人工制品。
   - 如果这回合能斩杀：**直接跳到第 3 层终结线**，所有成长/防御溢出都被覆盖。

**输出**：这一回合是 **Stabilize（买时间）** 还是 **Spike（创造/兑现窗口）**。

## 2. 第 1 层：生存下限（不做会死的部分）

在考虑任何进攻/成长之前，先算：

### 2.1 入伤

```
incoming = Σ(敌人 attack intent 的 total_damage 或 damage × hits)
```

- 多段攻击要乘段数；A10 常见 8×4=32、14×2=28、10×2=20、9×2=18。
- 敌人有 Strength/Weak 时修正；玩家有 Weak 只影响自己攻击，不影响敌人打你。
- 敌人有 `Ringing`（每回合只能 1 张牌）或 `Smoggy`（每回合只能 1 张技能）时，先看限制，再谈牌序。

### 2.2 格挡

```
block = Σ(卡牌格挡) × (Frail ? 0.75 : 1) + Plating(回合结束) + 遗物/能力
```

- **Frail 脆弱**：卡牌格挡 -25%；算的时候先乘 0.75。
- **Plating 覆甲**：岩石铠甲 4 层，通常在回合结束给格挡；它是“预埋生存”，要算进本回合。
- **Barricade 壁垒**：格挡不被清除，下回合继续用；但 3 费可能挤占本回合防御。
- **Shrug It Off**：8 甲 + 抽 1，是“附带收益的防御”，优先级高于纯 Defend。
- **Evil Eye**：8 甲；本回合若已消耗过牌，再 +8，配合烧牌极强。
- **True Grit**：7 甲 + 随机消耗；格挡合格，但随机消耗可能扔掉关键牌（见第 8 节）。
- **Blood Wall**：16 甲，但 -2 HP；HP ≤2 时不能打。**低血时不要只看 16 甲**：先和 Flame Barrier/Shrug 比“有效生存”。HP 9、敌人 13 攻时：
  - Blood Wall：9→7 HP，16 甲，吃 0，无反伤，净 7 HP；
  - Flame Barrier+：9→8 HP，12 甲，吃 1，反伤 4，净 8 HP + 4 伤害。
  - **Flame Barrier 严格更优**；Blood Wall 只在 HP 安全、确实需要 16 甲时用。
- **Flame Barrier**：12 甲 + 反伤 4；面对多段攻击/低血时优先级高于 Blood Wall（没有自伤成本）。
- **Rage**：0 费，本回合每打一张攻击 +3 甲；要在攻击前打，不是攻击后。

### 2.3 生存否决项

- 如果 **block < incoming**，先问：哪部分伤害必须挡（会死/触发致命后续），哪部分可以主动吃？
- **主动吃伤害是允许的**，但必须是算过的选择，不是算漏。
- 如果生存下限无法满足：
  - **不要打纯成长牌**（Demon Form / Inflame / Barricade / 引擎 Power），除非你有绝对把握下回合恢复节奏。
  - 优先用“防御+抽牌/烧牌”的牌（Shrug / Evil Eye / True Grit）同时完成生存与信息扩展。
  - 低血时不要用自伤牌（Blood Wall / Offering / Breakthrough / Brand / Inferno）去换节奏，除非这一下能直接结束战斗。
  - **能用 Flame Barrier / Shrug / Evil Eye 时，不要先用 Blood Wall**：低血时 16 甲不等于更强，-2 HP 和缺反伤会让它更差。

## 3. 第 2 层：节奏转化（生存满足后，这一回合能买到什么）

生存下限覆盖后，剩余能量/手牌进入投资阶段。按优先级：

### ① 零费/低费高杠杆动作

- **Bloodletting 放血**：0 费，-3 HP，+2 能量；HP 安全且生存已覆盖时，几乎是免费节奏扩展。
- **Offering 祭品**：0 费，-6 HP，+2 能量，抽 3；强，但 HP 低时是自杀。
- **Battle Trance 战斗专注**：0 费抽 3，但本回合不能再抽；**放在其他抽牌之后**，不要第一个打。
- **Rage 狂怒**：0 费，攻击前打，白嫖格挡。
- **Havoc 破灭 / Brand 烙印 / Spite 怨恨 / Body Slam 全身撞击**：0–1 费，低机会成本；但 Havoc/Cinder 会消耗牌，见下。

### ② 启动窗口 vs 兑现窗口

- **启动窗口**：引擎未就位，且生存压力允许本回合低输出。
  - 先打引擎（Corruption / Dark Embrace / Feel No Pain / Demon Form / Barricade），但**先算打完引擎后剩余能量/手牌是否仍能覆盖生存下限**。
  - 如果打引擎会导致本回合挡不住，推迟引擎，先活。
- **兑现窗口**：引擎已运转，或敌人进入收尾射程。
  - 把资源集中到“直接终结/显著削威胁”的动作。
  - 易伤在爆发前挂；多段攻击在力量/易伤窗口内打，不分散到无增益回合。

### ③ 烧牌在回合内的位置

烧牌不是“为了烧而烧”，先问：**烧掉这张后，本回合/下回合抽牌质量是否提升？**

- 手里有确定废牌（基础打击/防御、愧疚、状态牌），且能量允许 → 烧牌优先级高。
- 烧牌本身消耗太多能量，导致本回合生存/输出不足 → 推迟。
- **Cinder/Havoc 消耗的是抽牌堆顶，可能烧掉关键牌**；关键回合不要赌。
- **True Grit 随机消耗手牌**；手里有关键防御/收尾时不要先打（第 4 局真实教训）。
- **Fiend Fire/Stoke 消耗整手牌**；打之前确认手里没有唯一收尾。

## 3.5 回合之间的规划与取舍（第 12 局补）

出牌不只看“这回合怎么过”，还要看“下下回合怎么打”。三种资源可以提前铺：

| 想做的事 | 提前铺什么 | 代价 |
|---|---|---|
| 下回合爆发 | 这回合先挂易伤（雷霆/Bash）、先叠力量（燃烧）、先铺覆甲（岩石铠甲） | 少打一点本回合输出 |
| 下回合活命 | 这回合先铺 Plating/叠大甲/留格挡牌 | 少打一点输出 |
| 下回合斩杀 | 这回合把敌人压到斩杀线以下（而不是溢出到别的目标） | 本回合伤害分散 |

**判断顺序**：

1. 这回合不挡会不会死？会 → 先挡。
2. 不会死 → 有没有值得提前铺的东西（易伤/力量/覆甲）？有 → 铺，但要保证下回合能兑现。
3. 都不会 → 打伤害，并尽量把伤害打到“下回合能收掉”的目标上。

**易伤 vs 防御的取舍**（不是二选一，而是排序）：

- 挡住之后**下回合能反打** → 用最少防御保命，剩下的能量全上易伤/引擎。
- 挡住之后**下回合还是打不动** → 全挡，先活到能反打的窗口。
- **易伤会衰减**：跨回合的易伤通常到下一回合就没了；AOE 想吃到 1.5 倍，必须**同一回合内**先上易伤再打 AOE。

## 4. 第 3 层：能量与牌序的微观工程

### 通用牌序

1. **抽牌/能量扩展在前，消耗资源的动作在后**。
   - 先 Shrug / Pommel / Bloodletting / Offering / Burning Pact，再打高费攻击。
   - 例外：**Battle Trance 最后打**（它禁止本回合继续抽牌）。
2. **易伤/虚弱在对应动作之前**。
   - Bash/Uppercut/Taunt/Shockwave 先上，再打攻击。
   - 但敌人有 **Artifact** 时，易伤会被挡；先用低价值 debuff 破，或直接伤害。
3. **斩杀优先于一切未来价值**。
   - 有终结线就直接走；多拖一回合的期望损失通常大于成长收益。
4. **不要在手牌信息不完整时做不可逆承诺**。
   - 有抽牌手段先用（Shrug/Pommel/Offering），把信息拉满，再决定高费牌打哪张。
   - 抽牌后手牌未知：**只把抽牌牌单独发出去（不写 end）**，读新 `ctx` 再排下一手；
     同一 `seq` 里写“抽牌牌 + 抽牌前不在手里的牌”会被 `act` 以 `抽牌边界` 整手拒绝。
   - 但 Battle Trance 会关闭后续抽牌，放最后。

### 特殊牌序

- **Body Slam 全身撞击**：在格挡建立**之后**打；先 Defend/True Grit/Blood Wall，再 Body Slam。
- **Rage 狂怒**：在攻击**之前**打；否则 0 费白板。
- **Feel No Pain / Dark Embrace**：在消耗动作**之前**打；否则当回合不触发。
- **Corruption 腐化**：在技能牌**之前**打；但 3 费，先确认生存。
- **Barricade 壁垒**：在格挡牌**之前**打；但 3 费，先确认不会因此挡不住。
- **Juggernaut 势不可当**：在格挡动作**之前**打；每次获得格挡触发 5 伤。
- **Demon Form 恶魔形态**：在回合开始前/生存覆盖时打；当回合无收益。
- **Inflame 燃烧**：在攻击**之前**打；+2 力量只影响后续攻击。
- **Bash 痛击**：如果后续还有 2+ 攻击，先 Bash 上易伤收益最大；如果只有 1 张攻击，先算是否值得。
- **True Grit 坚毅**：放在关键牌都打完、手里只剩废牌时；不要第一张打。
- **Cinder 余烬 / Havoc 破灭**：抽牌堆顶未知时，关键回合不要赌；如果已知顶牌是废牌再用。

### 击杀后的再锚定（关键）

**每打出一张牌后，不只要重读手牌/能量，还要重读敌人。**

- 敌人死了会**移除**，剩下的敌人索引会前移；
- 敌人意图会刷新：原本攻击的怪可能变成 Buff/Status；
- 旧计划里的“这回合要吃 13 攻”“要挡 22”可能已经不成立。

**规则：**

1. 任何敌人死亡/召唤/意图变化后，**丢弃旧计划**，重新算 `incoming`。
2. 如果 `incoming == 0`：默认打攻击/引擎/过牌；纯防御只有在“为 Body Slam/Barricade/Feel No Pain/保留格挡做铺垫”时才打。
3. 不要因为“上回合它要打 5”就继续打 Defend——先看它现在还在不在、还打不打。
4. 目标索引以**当前**敌人列表为准；击杀后重新读 `/state`，不要用旧索引。
5. **不要在状态过渡时结束回合**：出牌后 0.2–0.5 秒内，mod 可能返回“手牌 0/能量未扣”的过渡快照；如果 `end_turn` 还不在 `available_actions` 里，就等稳定玩家回合，不要发送。`sts2.py` 现在会等待合法动作并做“手牌突然清空但能量没扣”的告警。

**第 6 局实例**：场上「塞牌 / 塞牌 / 攻击 5」，先用两刀打死攻击怪；此时只剩两个只上状态的怪，`incoming=0`，却还是打了 Defend。正确是继续攻击/引擎，Defend 那 1 费是白扔的。

## 5. 第 4 层：结束回合前的状态检查

按顺序过：

1. **下回合生存是否预埋？**
   - Barricade 是否保留格挡？
   - Plating 是否会在回合结束给甲？
   - Feel No Pain/Dark Embrace 是否已就位，使下回合消耗附带格挡/抽牌？
   - 是否有 Blur/残影等“保留格挡”效果？
2. **能量是否浪费？**
   - 还有能量，且手牌有合法、不污染牌库/不给敌人增益的牌 → 考虑打出。
   - 不要为了“用光能量”打会破坏循环/给敌人 Buff 的牌。
3. **手牌留到下回合是否会变死牌？**
   - 高费牌 + 下回合能量不确定 → 本回合用 Bloodletting/Offering 预存能量，或先打掉。
   - 保留牌（Retain）要留关键防御/收尾，不要乱丢。
4. **药水/遗物是否该用？**
   - 斩杀差一点、生存差一点时，药水就是“买一次额外启动”。
   - Duplicator 复制关键牌（Body Slam/Blood Wall/Cinder），不要复制随机小牌。
5. **敌人状态是否遗漏？**
   - 敌人格挡、Artifact、Thorns、Ringing/Smoggy、召唤物、死亡触发。
   - **爪牙（Minion）不是无条件“只打本体”**，按三个分支判断：
     1. 本体 2 回合内可杀 / 本体血量低 → 无视爪牙直杀本体（爪牙随本体消失）；
     2. 本体 HP ÷ 你每回合输出 > 4 回合，且爪牙贡献 ≥40% 入伤 → 先清威胁最大的爪牙；
     3. 爪牙会叠力量、给本体增益、或持续补召唤 → 优先清，别让它滚雪球。
   - 每次召唤/增益后重算；先看召唤者会不会补，会补就回到分支 1。
6. **0 费牌清理（结束前必看）**
   - 手牌里有没有 0 费、可打、还能造成伤害/抽牌/格挡的牌？有就先用掉。
   - **Spite 怨恨** 0 费 6 伤；**Anger 愤怒** 0 费 6 伤；**Bloodletting 放血** 0 费 2 能量；**Battle Trance 战斗专注** 0 费抽 3。
   - 唯一例外：会被 Thorns/自伤打死，或 Battle Trance 会关闭你还需要抽的牌。
   - 第 7 局 Toadpole 战：Spite 0 费在手里，却先武装+防御就结束回合；免费 6 伤没打，导致后面多拖一回合、多吃伤害。

## 6. 一页检查清单

```
1. 敌人意图 + 斩杀线：这回合能斩吗？→ 能斩，直接终结线。
2. 生存下限：不做什么会死？用最少资源覆盖；优先附带抽牌/烧牌的防御。
3. 零费/低费杠杆：放血、0费抽牌/烧牌，先扩大可选空间。
4. 启动 vs 兑现：引擎未就位且活得下去 → 引擎；引擎已就位/进入射程 → 集中兑现。
5. 牌序：抽牌/能量在前；Battle Trance 最后；易伤在输出前；Body Slam 在格挡后；True Grit 在废牌时。
6. 结束检查：下回合生存/能量是否预埋？有没有白扔能量/手牌/药水？
7. 危机检查：不喝药会不会死？药水能不能买一回合/买斩杀？
8. 击杀检查：敌人数量/意图变了吗？incoming 现在还是 0 吗？旧计划还成立吗？
9. 0 费检查：有没有 0 费可打的伤害/抽牌/格挡留在手里？有就先用（除非 Thorns/自伤致死）。
```

## 7. 伤害/格挡公式（STS2 字段）

```
incoming = Σ intent.total_damage（存在就直接用，它已经是本回合最终值：
           含敌力量/敌虚弱/玩家易伤/段数，不要再乘段数或再乘易伤）
           仅当 total_damage 为空时：
           Σ [(damage + 敌力量) × (敌虚弱 ? 0.75 : 1) × (玩家易伤 ? 1.5 : 1)] × hits
block    = Σ card block × (Frail ? 0.75 : 1)
           + Plating（回合结束）
           + 遗物/能力格挡
outgoing = Σ [(base + Strength) × (Vulnerable ? 1.5 : 1)
           × (Weak ? 0.75 : 1)] - 敌人格挡
status   = 可格挡状态伤害进 block 池；无视格挡失血（呼唤/悔恨）直接进 taken
lethal   = 单体/AOE/伤害药水按 sim 实际结算 ≥ 敌人 HP+格挡
           （P1-2 起 calc.lethal 同时覆盖 AOE 与药水；见 [`PLAN_VISIBILITY.md`](PLAN_VISIBILITY.md)）
```

完整口径、状态牌表和已知边界见 [`COMBAT_MATH.md`](COMBAT_MATH.md)。

- 敌人有 **Artifact**：易伤/虚弱会被挡一次；先破或直接伤害。
- 玩家有 **Weak**：攻击伤害 -25%；玩家有 **Frail**：卡牌格挡 -25%。
- **The Boot**：≤4 伤害变 5；小伤害多段时会影响精确计算。
- **Ringing**：每回合只能 1 张牌；**Smoggy**：每回合只能 1 张技能牌。先看限制再排牌序。

## 8. 我们的实战补丁（失败模式）

1. **True Grit 随机消耗关键牌**
   - 第 4 局：True Grit 把 Defend/Body Slam 消耗掉，导致少挡少打。
   - 规则：手里有关键防御/收尾时，True Grit **最后打**；只在手里有废牌时用。
2. **Battle Trance 打太早**
   - 它禁止本回合继续抽牌；先 Shrug/Pommel/Offering，再 Battle Trance。
3. **牌序错：先攻击后上易伤**
   - Bash/Uppercut 先上易伤，再打后续攻击；只有 1 张攻击时先算期望。
4. **Body Slam 在格挡前打**
   - 先建立格挡，再 Body Slam；否则伤害=0。
5. **忽略敌人格挡/Artifact**
   - 斩杀线要减敌人格挡；易伤要被 Artifact 挡一次。
6. **Smoggy/Ringing 下按常规牌序**
   - 只能 1 张技能/1 张牌时，先选“能活/能杀”的那张，不要按“先抽牌后攻击”的惯性。
7. **召唤者战先清小怪**
   - 活雾/Gas Bomb：杀活雾，小怪自动消失；不要先清炸弹。**前提是本体血量在 2–4 回合射程内**；本体 199 血而爪牙每回合打 20+ 时，按第 5 节的三分支先清爪牙（第 10 局 Kin Priest）。
8. **低血自伤**
   - Blood Wall/Offering/Breakthrough/Brand/Inferno 在低血时先算“自伤后是否还活着”。
9. **手牌索引移位**
   - 每打一张牌后重新读 `/state`；用 `python tools/sts2.py play <CARD_ID>` 按卡牌 ID 出牌，避免旧索引。
10. **药水留到死**
    - Boss/精英差一点时，抽牌/格挡/复制药水就是额外启动；该喝就喝。
11. **硬吃致死伤害不查药水**
    - 危机回合先清点药水；不喝必死时，药水不是“留给 Boss”的，是现在买命的。
12. **击杀后按旧意图打防御**
    - 攻击怪死了，剩下的怪只上状态，却继续 Defend；先重读敌人列表和 incoming，再决定。
13. **0 费牌留在手里**
    - Spite/Anger/Bloodletting/Battle Trance 这种 0 费牌，结束前没打；免费伤害/抽牌/能量直接浪费。
14. **在状态过渡时结束回合**
    - 出牌后拿到“手牌 0/能量未扣”的过渡快照，误以为没牌了；先等 `play_card/end_turn` 合法且状态稳定，再结束。 
15. **荆棘用血硬撞**
    - 面对 Thorns/尖刺，先叠格挡再攻击：荆棘反伤会被格挡吸收。第 10 局双蟾蜍战用 4 点血换输出，本可以零损耗。
16. **Boss 前拿药水换牌**
    - 药水是“买一回合”的确定性资源；Boss 前把格挡/虚弱药水换成普通牌，等于把危机时的解交给随机抽牌。第 10 局 Boss 第 5 回合 33 点入伤时无药可救。
17. **15 张之后继续加牌**
    - 牌组 ≥16 时只收质变牌；Boss 前 3 层默认跳奖励。厚牌组会在关键回合抽不到格挡牌（第 10 局 Boss 关键回合 0 张防御）。
18. **低血打自伤牌**
    - Blood Wall/Offering 在 HP ≤2 时不要打；-2 HP 会直接致死，手里的血墙等于废牌。
19. **爪牙盲从“只打本体”**
    - 第 10 局 Kin Priest 199 血，两只爪牙合计 21 点/回合（本体 12），按“爪牙随本体消失”硬打本体，6 回合没杀掉、反被爪牙磨死。本体血量远超输出时，先清一只爪牙能把入伤砍掉 40%。
20. **AOE 在易伤之前打**
    - 第 12 局第 14 层、第 11 层：突破+ 出手时上一回合的易伤已经衰减，每只只吃到 15 而不是 22。AOE 想吃到易伤，必须**同一回合内先上易伤**。
21. **用单体重击收残血**
    - 有两个敌人时，用打击/剑柄收一个残血，另一个完全没掉血；用雷霆/突破收尾可以顺带削另一个目标 4–13 点。
22. **只看眼前回合，不铺下一回合**
    - 不提前挂易伤/叠力量/铺覆甲，下一回合的爆发打不满；反过来，第 12 局第 1 回合铺覆甲、第 4 回合雷霆+突破打 67 群伤，就是正确示范。
23. **为剥人工制品浪费关键牌**
    - 带 Artifact 的敌人，剥一次要浪费一张牌 + 能量；剥的成本高于收益时，干脆不打 debuff，直接堆伤害。
24. **自伤牌收尾**
    - 突破 -1 血、血墙 -2 血：打击/痛击也能收的残血，不要吃这点血；低血时自伤更要先算活不活。
25. **药水槽满了就放弃**
    - 槽满不是“不能拿”，而是要取舍：丢掉对当前战略没用的（单卡检索之类）、喝掉回血药水腾位置、或丢掉再拿强药水。

## 9. 三个例子

### 例 1：3 HP，Ringing，敌人 19 攻

- 只能出 1 张牌；手里 Defend（5 甲）、Strike（6 伤）。
- 出 Defend：吃 14，HP -11 → 死；出 Strike：吃 19 → 死。
- 如果手里有 Blood Wall（16 甲，-2 HP），出它：HP 3→1，挡 16，吃 3 → 死；也不行。
- 正确做法是在更早回合预埋格挡/药水，而不是到 3 HP 才找解。
- **结论**：Ringing 回合的生存要在前一回合预判；不要把所有防御留到最后一回合。

### 例 2：True Grit 与关键牌

- 手牌：Defend、Body Slam、True Grit、Strike；敌人 24 攻。
- 错误：先 True Grit → 随机消耗可能扔掉 Defend/Body Slam，导致挡不住或 Body Slam 打不出。
- 正确：先 Defend（5 甲），再 Body Slam（5 伤），最后 True Grit（9 甲 + 消耗废牌）；或先打掉关键牌再 True Grit。
- **结论**：True Grit 是“最后一张”的牌，不是起手牌。

### 例 3：活雾与 Gas Bomb

- 活雾 80 HP，Smoggy（每回合 1 张技能）；Bloat 召唤 Gas Bomb。
- 错误：先清 Gas Bomb，活雾继续召唤，输出被衍生物吸走。
- 正确：所有伤害打活雾本体；活雾死，Gas Bomb 自动消失；每回合只出 1 张技能。
- **结论**：目标优先级是“召唤者本体”，不是小怪。

## 10. 危机回合与药水：不要硬吃致死伤害

**触发条件**（任一满足就进入危机模式）：

- 本回合不挡/不全挡，HP 会 ≤0；
- 挡完会掉到“下一次攻击必死”的区间（约 ≤15% max HP，或 ≤ 敌人下一击）；
- 面对精英/Boss 的高额多段，硬吃后下回合无法恢复节奏。

**危机模式的第一步不是出牌，是清点药水/遗物：**

1. 先找**确定性**生存/斩杀：格挡药水、虚弱药水、血墙/火屏/Defend、能斩杀的攻击药水。
2. 没有确定性答案时，才用药水**赌**：技能药水（找防御/抽牌）、速度药水（敏捷/抽牌）、复制药水（复制关键防御）。
3. **在打出第一张高费/自伤牌之前用药水**；不要先血墙把自己压到 7 HP，再想起来喝药。
4. 用药水后立刻重读手牌/能量；技能药水会加牌，可能改变牌序。

**药水优先级：**

| 药水 | 用途 | 注意 |
|---|---|---|
| 格挡药水 | 确定性挡大伤害 | 最稳，低血优先 |
| 虚弱药水 | 降低敌人本回合伤害 | 多段/高攻时价值高 |
| 技能药水 | 找防御/抽牌/烧牌 | 盲盒；可能给 Primal Force 这类非防御，不能当稳定挡 |
| 速度药水 | 敏捷/抽牌 | 先喝再打防御，甲会变高 |
| 攻击/爆炸/能量药水 | 斩杀线 | 只在本回合能杀时用 |
| 复制药水 | 复制关键牌 | 先复制 Blood Wall/Flame Barrier/Body Slam，不要复制小攻击 |

**硬规则：**

- **绝不在“不喝药必死”的回合把药水留到 Boss。** 现在活不下来，就没有未来的 Boss。
- 药水是“买一回合”的资源；危机回合用掉是正收益，不是浪费。
- 如果药水是盲盒（技能药水），先算最坏结果；没有确定性解时，赌比确定死好。
- 低血时优先 **Flame Barrier / Shrug / Defend**，不要先 Blood Wall（详见第 2.2 节）。

### 第 5 局反例

- 27 HP、32  incoming，手里还有 **技能药水**；没有先喝，而是直接 Blood Wall + Strike，之后掉到 9 HP。
- 9 HP 才喝技能药水，出了 Burning Pact（不是防御），然后又在 9 HP 打了 Blood Wall。
- 到 7 HP、22 攻时已经没有药水；只能硬吃，死亡。

**正确顺序**：27 HP 先清点药水 → 若没有确定性 32 甲，先喝技能药水/速度药水找防御 → 再决定 Blood Wall/Flame Barrier/Strike；不要等到 9 HP 才赌。
