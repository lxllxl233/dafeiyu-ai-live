# 敌人机制（已并入 skill）

> 完整速查：`games/slay-the-spire-2/decision/knowledge/ironclad/references/enemies.md` v3（按幕/遭遇，87 场，含编成/HP/打法）。
> 战斗内以 `state` 的 `MECHANICS` 为准；本文件只留最容易被本地库或旧攻略写错的机制。

| 敌人 | 容易记错的地方 |
|---|---|
| 花园幽灵鳗 | 胆小 = 每回合首次被命中 **+6/7 格挡**（本地文案写 +1 是错的），多段能吃掉 |
| 鬼祟珊瑚群 | 硬化外壳 **20/回合**（v0.106 后）：打满 20 就停手叠甲 |
| 骇鳗 | 尖叫：≤50% 血首次眩晕（70/A10:75），醒后挂 **99 层易伤** |
| 仪式兽 | 首次 ≤150 血（A10 160）眩晕；Ringing 回合只能打 1 张牌 |
| 同族神官 | 本体 190（A10 199）+ 信徒；本体厚时先清一只信徒止损 |
| 地道虫 | 埋地：格挡不随回合消失，打空全部格挡 → 眩晕 |
| 盛碗虫（石） | 失衡：攻击被**完全格挡** → 眩晕（算准挡满换一回合） |
| 双尾鼠 | 呼唤后援 = 召唤：T1 就集火本体，绝不分散 |
| 活雾 | Smoggy 每回合只能 1 张技能；本体死 Gas Bomb 自动消失 |
| 瀑布巨兽 | 蒸汽喷发：死亡后下回合爆炸，杀前先上虚弱（×0.75） |
| 实验体 | 适者生存：死亡复活变强；每 2 回合 +1 无实体 |
| 女王 | 魂缚锁链：每回合前 3 张抽牌变 Bound；脆弱/易伤/虚弱 99 |

查询单只：`python tools/gamedb.py enemy <ID>`。
