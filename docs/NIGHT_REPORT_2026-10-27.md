| 知识恶魔（第二幕） | 399 | 40–50 | 18–28 | 最多 45（T11） | 差 2–4 回合 DPS |
| 第三幕单只 | 630 / 636 / 667 | 40–50 | 18–28 | 32→97 | 结构性差距 |
| **第三幕 A10 双 Boss 连战** | **1165–1266** | 40–50 | 18–28 | — | 需要「防御也必须复利」 |

**核心公式**：输出是复利的（滚石/势不可当/暴走），**防御是线性的（防御牌只有 5–11 甲）**。
第二幕还能靠血厚硬顶，第三幕 Boss 入伤从 32 涨到 97 时，线性防御必然崩。

### 3.1 第三个墙：成长型入伤（run73 新证据）

run73 打同族（THE_KIN）时把这条规律看得最清楚——满血 80 进战，前四回合靠「防御 + 覆甲 + 耸肩」做到单回合 0 伤，
但随着祭司每回合加力量，入伤曲线是 **14 → 21 → 19 → 8 → 33 → 28 → 29 → 30 → 37**，
而我的甲牌只有 7 张（4 防御 + 耸肩 + 血墙 + 坚韧之环），三费回合的甲上限 21–26。
**T8 起每回合净掉 17–20，80 血撑不到祭司 199 血见底。**

结论升级为两条：
1. **牌组要薄**（≤16）——解决「手上有引擎没甲 / 有甲没引擎」；
2. **甲牌要占比 ≥ 45%**——解决「成长型入伤」。7/17 = 41% 都还不够，因为里面有一张是扣血换甲的血墙。

## 4. 今晚修了什么代码

### 4.1 `tools/act.py`
1. **`fx` 报错自带答案**（今晚踩了 4 次：`fx.hp` / `fx.e` 手算和模型差 1–5 点，每次都要重发一次请求）。
   现在 err 直接写 `改成 "hp": 74 重发，或删掉 fx.hp`。
2. **遗言告警（新）**：新增 `_death_damage_risk()`，扫敌人身上的「蒸汽喷发 / 爆炸 / 亡语 / 自爆」等词条。
   - 清场且 0 甲时给 `warn: 遗言警告`（run72 瀑布巨兽的 44 点 DeathBlow 就是这类，靠这条以后不会再漏算）；
   - 能斩杀但斩杀线 0 甲且敌人有遗言时，`护栏·漏斩` 会要求换「带甲的斩杀线」。

### 4.2 `tools/gates.py`（新工具）
把三条门槛做成可执行检查，不靠自觉：
```powershell
python tools/gates.py --act 2
# PASS 第2幕 牌组张数 = 15 （要求 <=16）
# PASS 第2幕 甲牌占比 = 47% （要求 >=0.45）
# FAIL 第2幕 抽牌张数 = 2 （要求 >=3）
```
配套 `tools/test_gates.py`（8 项，全绿）。这是今晚最实用的产出：以后每次拿牌就能自查，不用等死。

### 4.3 `tools/act.py` 之二：漏甲误判
`护栏·漏甲` 原来用「回合起手手牌」判断，导致**已经打出两张防御再 end 仍被拦**（run73 实测，等于罚做对了的人）。
现在 `_played_counts()` 会扣掉这一手已经打出的甲牌（同名多张按张数扣），测试从 10 项扩到 **12 项**。

### 4.4 `.dsh/skills/sts2-ironclad-ironclad/SKILL.md`
新增 8 条实战规则（全部今晚实测）：
- **SL 不改变抽牌顺序**（`save_and_quit` → continue 后开局手牌完全一样）→ SL 只能修操作，不能刷牌序；
- **商店每店只能删 1 张牌**；
- **药水栏满时 `claim_reward` 静默成功但不给药水**（run72 白丢一瓶明耀酊剂）；
- **遗言敌人斩杀不等于安全**（见上）；
- **`fx` 报错会带答案**，照抄重发；
- **`贪婪` 是永恒诅咒，商店删不掉**（诅咒珍珠的隐藏代价）；
- **「从牌组移除 N 张」的多选界面点不动**（blocker，`docs/TODO_mod_deck_remove.md`，绕过：别选 + `save_and_quit`/`continue_run` 回滚）；
- **只堆甲会死于消耗战**，甲牌 ≥45% 必须配「非基础高伤攻击 ≥2」。

2. **必须拿 3 张以上抽牌**（耸肩无视、战斗恍惚、献祭、祭品），否则「引擎在手上、甲在牌堆里」的局必死。
