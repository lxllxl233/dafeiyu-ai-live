**核心公式**：输出是复利的（滚石/势不可当/暴走），**防御是线性的（防御牌只有 5–11 甲）**。
第二幕还能靠血厚硬顶，第三幕 Boss 入伤从 32 涨到 97 时，线性防御必然崩。

### 3.1 第三个墙：成长型入伤（run73 新证据）

run73 打同族（THE_KIN）时把这条规律看得最清楚——满血 80 进战，前四回合靠「防御 + 覆甲 + 耸肩」做到单回合 0 伤，
但随着祭司每回合加力量，入伤曲线是 **14 → 21 → 19 → 8 → 33 → 28 → 29 → 30 → 37**，
而我的甲牌只有 7 张（4 防御 + 耸肩 + 血墙 + 坚韧之环），三费回合的甲上限 21–26。
**T8 起每回合净掉 17–20，80 血撑不到祭司 199 血见底。**

结论升级为两条：
1. **牌组要薄**（≤16）——解决「手上有引擎没甲 / 有甲没引擎」；
2. **甲牌要占比 ≥ 45%**——解决「成长型入伤」。7/17 = 41% 都还不够，因为里面有一张是扣血换甲的血墙。

## 11. 本轮最大收获：仪式兽的「横冲直撞」是白送回合

仪式兽的血线机制之前一直没搞对。实测：

- **阈值是 160（不是机制文案写的 150）**，血量第一次跌破 → **当回合的攻击直接取消**（不是下回合）。
- **每 3 回合一次「眩晕」**（本回合只能出 1 张牌）：T7、T10、T13…
- 出招循环固定：B（无伤）→ A20/A22/A24/A26（每次 +2 力量）→ 跌破阈值晕 → B → A17 → A19+B → B → A21…

**打法**：前期全挡，把血线**精确踩到 160 以下**换一整回合免费输出，然后按循环排牌。
run81 的斩杀线是 **T11 精确 21 点**（愤怒 + 打击），三次尝试的曲线：T12 死（剩 60）→ T11 必死前 SL → **T11 斩杀**。

## 14. `tools/dps.py` 的判决（这是今晚最重要的一张表）

run81 进第二幕时的牌组：

```
牌组 19 张：攻击 10 / 格挡 6 / 打击防御 10
--> 估计净输出 25.3 / 回合

知识恶魔 459 血 → 18.2 回合（硬截止 10）❌
帝皇蟹   300 血 → 11.9 回合（硬截止 8） ❌

```

**第二幕 Boss 要 8-10 回合打完 → 需要净输出 ≈50。我们常年 25-30。**
剩下 5-8 个回合的伤害缺口，靠操作是补不回来的 —— 所以前 13 局的复盘一直在错误的问题上优化。

**四个提高净输出的杠杆（已写进 RUN_DOCTRINE）**：
1. **删打击**（同时抬 DPS 和抽牌质量，一个动作解决两个问题）

3. **第一幕必须带 1 张收尾牌**（重锤/暴走/契约终结/恶魔之焰/旋风斩）—— 优先级高于「甲牌占比 ≥45%」
4. 0 费攻击（小刀/愤怒/飞剑）喂双截棍 → 白嫖能量

## 15. 本轮的「教科书操作」

零成本换牌，直接把净输出从 25 抬到 ~40。以后每局都要找这种「丢废牌换好牌」的事件。

这也是「升级牌 > 加牌」的最好例子。
