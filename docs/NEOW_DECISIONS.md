# 开局 / Neow 决策（A10 铁甲战士）

> Neow 不是“选最安全的”，而是选**最稀缺、最能提高整局上限**的资源。
> 先列清所有选项的成本/收益，再比较“商店能不能补”。

## 0. 第 7 局反例

Neow 三个选项：

| 选项 | 效果 | 成本 |
|---|---|---|
| 精准剪刀 | 移除 1 张牌 | 无 |
| 药瓶皮套 | +1 药水槽，获得 2 瓶随机药水 | 无 |
| 树叶药膏 | 变化 1 张打击 + 1 张防御 | **失去 12 点最大生命** |

我选了 **精准剪刀（删 1 张打击）**，这是错的。

**为什么树叶药膏更好：**

1. 当时路线是 **3 商店**；删牌在商店随时能买，**并不稀缺**。
2. 变化 2 张基础牌是 Neow 独有的资源：把 2 张最差的打击/防御换成 2 张随机牌，**上限远高于删 1 张**；可能直接出引擎/防御/AOE。
3. -12 最大生命是成本，但 A10 开局 64/80，仍有 3 营火 + Burning Blood；血线可以靠路线和睡觉兜住，**一次 2 变换的机会买不到**。
4. 药瓶皮套只是临时资源，不改善牌组质量；在牌组还有 9 张基础牌时，不如变 2 牌。

**错误本质**：我把“删牌=最稳”当成默认，没算**稀缺性**（商店能补）和**上限**（变 2 牌能出引擎）。

## 1. Neow 决策四问

1. **这个资源商店能补吗？**
   - 删牌、买牌、买药水、升级：商店/营火能补；
   - **变化 2 张牌、开局遗物、金币**：Neow 独有，稀缺性更高。
2. **它改善牌组质量，还是只给临时资源？**
   - 变 2 牌 > 删 1 牌 > 2 瓶药水（通常）。
3. **血量成本能不能被路线兜住？**
   - -12 最大生命：看当前血线、接下来有没有营火/商店；有 3 营火时成本可控。
   - 如果当前血线会掉到 50% 以下且前面没有营火，才降低变换优先级。
4. **最坏结果能不能接受？**
   - 变 2 牌可能低roll，但低roll也只是 2 张可删的牌；删 1 牌的上限只有“少一张基础牌”。

## 2. 常见 Neow 选项优先级（A10 默认，按实际路线调整）

| 档位 | 选项 | 说明 |
|---|---|---|
| S | **变化 2 张基础牌**（树叶药膏类） | 2 张牌质变，商店补不到；HP 成本可控时优先 |
| A | 删 1 张牌 | 稳定，但商店能补；路线商店少时提高 |
| A | 金币（无永恒诅咒） | 能转成删牌/防御/药水；注意别拿永恒诅咒 |
| B | +药水槽/2 药水 | 危机容错，但不改善牌组质量 |
| B | 升级 1 张关键牌 | 若正好是 Bash/Cinder/True Grit 等质变牌 |
| C | 回血/最大生命 | 只有血线极低且前面没营火时才考虑 |
| 避免 | 带**永恒诅咒**的金币 | 永恒诅咒删不掉，牌组永久多一张死牌 |

## 3. 决策检查清单

```
1. 列出每个选项的成本/收益（HP、最大HP、金币、药水、牌组变化）。
2. 问：这个资源商店能不能补？能补的降权。
3. 问：它改善牌组质量，还是只给临时资源？
4. 问：血量成本能否被路线（营火/商店）兜住？
5. 问：最坏结果能不能接受？
6. 选期望值最高，不是选“看起来最安全”。
```
