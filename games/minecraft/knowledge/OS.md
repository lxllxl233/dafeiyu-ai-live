# 我的世界 · 生存开荒手册（第一天）

> 这份手册是给「只通过本地桥动作玩 MC」的决策层看的，不是给玩家看的攻略。
> 所有动作名和字段以 `prompts.py` / `engine.py` 的 `minecraft.action/v1` 为准；
> 数值以 `rules.py` 为唯一来源，别在这里另抄一套阈值。

## 目标

第 1 天结束前做到：**有工作台、有木镐、有熔炉、有火把、有一处能把 shelter 搭到
0.85 的落脚点**。第 2 天再考虑石镐、铁、床和房子。

判断顺序永远是：**先活过今晚 → 再补工具 → 再谈发展**。

## 时间轴（游戏内）

| 时段 | 时钟 | 该做什么 |
|---|---|---|
| 白天 | 06:00–18:00 | 砍树 → 工作台 → 木镐 → 挖圆石 → 熔炉 → 火把 |
| 黄昏 | 18:00–20:00 | 收尾：把材料带回落脚点，开始放方块搭遮挡 |
| 夜里 | 20:00–06:00 | shelter ≥ 0.85 就守着；不够就先放方块，别在野外站着 |

桥给的 `phase` 是 `day / dusk / night`，`clock` 是 `HH:MM`；黄昏就要开始往回走，
不要等 `phase=night` 才动。

## 硬规则

1. **工具等级**：挖圆石/煤要木镐，挖铁要石镐；空手只能挖树。
   合成后必须 `equip`，`held` 不对就挖不动。
2. **工作台要放下**：`craft crafting_table` 只是拿到物品，`place crafting_table`
   之后 `crafting_table=true`，木镐/石镐/熔炉/箱子才合成得了。
3. **熔炉同理**：`craft furnace` → `place furnace`，之后才能 `smelt`；
   烧一个东西要 1 块煤。
4. **天黑前把 shelter 搭到 0.85**：每放一个圆石/木板/原木/工作台/熔炉 +0.15，
   火把不算。没到 0.85，夜里每 9 秒会被僵尸打一次。
5. **饱食 ≤6 先吃**：面包 +5、熟牛肉 +8；生牛肉只有 +2，优先用熔炉烤。
   饱食到 0 会持续掉血。
6. **血 ≤8 不要硬拼**：先 `place` 方块挡、`goto home` 撤，或者干脆躲到天亮。
   有剑（木剑 4 / 石剑 5 / 铁剑 6 点伤害）才考虑主动清僵尸。
7. **一样失败两次就换目标**：合成失败通常是材料/工作台不够，挖掘失败通常是
   工具等级不够或附近没这种方块；重复同一个动作只会继续失败。

## 配方（一份产物）

| 产物 | 材料 | 要工作台 |
|---|---|---|
| 橡木木板 ×4 | 橡木原木 ×1 | 否 |
| 木棍 ×4 | 橡木木板 ×2 | 否 |
| 工作台 | 橡木木板 ×4 | 否 |
| 木镐 | 橡木木板 ×3 + 木棍 ×2 | 是 |
| 木剑 | 橡木木板 ×2 + 木棍 ×1 | 是 |
| 木斧 | 橡木木板 ×3 + 木棍 ×2 | 是 |
| 石镐 | 圆石 ×3 + 木棍 ×2 | 是 |
| 石剑 | 圆石 ×2 + 木棍 ×1 | 是 |
| 石斧 | 圆石 ×3 + 木棍 ×2 | 是 |
| 熔炉 | 圆石 ×8 | 是 |
| 火把 ×4 | 煤 ×1 + 木棍 ×1 | 否 |
| 箱子 | 橡木木板 ×8 | 是 |
| 铁镐 | 铁锭 ×3 + 木棍 ×2 | 是 |
| 铁剑 | 铁锭 ×2 + 木棍 ×1 | 是 |
| 铁斧 | 铁锭 ×3 + 木棍 ×2 | 是 |

熔炼：`raw_iron → iron_ingot`、`beef → cooked_beef`，每份耗 1 煤。

## 开荒顺序（本地策略也照这个走）

1. `mine oak_log 3`（附近有树就不用手动 goto，桥会走过去）；
2. `craft oak_planks 1` → 4 木板；重复到 ≥ 4，`craft crafting_table` + `place`；
3. 木头不够就再砍：木板 3 + 木棍 2（木棍先 `craft stick 1`，消耗 2 木板）；
4. `craft wooden_pickaxe` + `equip wooden_pickaxe`；
5. `goto stone` → `mine cobblestone 8`；`craft furnace` + `place furnace`；
6. `goto coal` → `mine coal_ore 2`；`craft torch 1`；
7. `place` 圆石/木板把 shelter 补到 ≥ 0.85；
8. 有余力：`craft stone_pickaxe` + `equip`，再去 `mine iron_ore 3` → 熔炼。

## 夜里怎么打

- 僵尸 20 血、每次反击 2 点（普通难度）；木剑 5 下、石剑 4 下、铁剑 4 下。
- 一只僵尸贴脸、血 > 8：可以边退边打；两只以上或没武器：放方块 + 撤退。
- `attack` 只打 6 格内的目标；太远会报「太远了，先 goto 靠近」。
- 天亮后敌对生物会消失，不用追。

## 常见错误

- 拿着原木直接 `craft stick`：不行，先 `craft oak_planks`。
- 没放工作台就 `craft wooden_pickaxe`：会被拒绝，`place crafting_table` 再来。
- 空手 `mine cobblestone`：会被拒绝，先做木镐并 `equip`。
- 夜里在野外 `wait`：等来的只有僵尸；要么放方块，要么挖材料。
- 一次塞 8 步：前一步失败整段白跑，1–5 步更稳。
- 把火把当遮挡：火把只照明，不加 shelter。

## 真机与仿真

- `source=http`：真机桥，`game state` 显示在线；`source=sim`：内置仿真世界，
  用于离线验收/演示；`source=offline`：桥没连上。
- 仿真世界和真机共用同一套动作协议；换成 Fabric 模组时 Python 端不换代码。
- 真机桥需要做的事：寻路（goto）、破坏/放置方块、合成检查、熔炼、攻击、
  读取背包/附近方块/时间。做不到的动作必须返回 `{"ok": false, "error": "..."}`，
  不要静默成功。
