# 铁甲战士流派强度表（v1，2026-10-25）

来源：https://slaythespire2.net/zh-CN/build/ironclad（正式版 v0.107.1，页面 2026-06-18）。
评级：S 消耗流 > A 力量流 ≈ A 格挡/全身撞击流 > B 易伤流 / 自伤流（综合成形速度、上限、高进阶稳定度）。

## S · 消耗流（本人主玩）

- **思路**：前期用坚毅/燃烧契约/重振精神清打击防御；中期无惧疼痛 + 黑暗之拥让每次消耗换格挡+抽牌；腐化让技能 0 费；收尾恶魔之焰 / 契约终结 / 卡戎之灰。
- **核心**：无惧疼痛（消耗得 3 甲）、黑暗之拥（消耗抽 1）、燃烧契约（1 费定向烧+抽 2/3）、坚毅（7 甲+随机烧，敲完定向）、恶魔之焰（2 费，消耗所有手牌，每张 7 伤）。
- **辅助**：腐化（先古限定）、重振精神（消耗所有非攻击，每张 5 甲）、契约终结（消耗堆 ≥3 → 0 费 AOE）、祭品（0 费 -6 血 +2 能 抽 3/5）、添柴（消耗整手，每张随机补 1）、邪眼（消耗过则 16 甲）、被遗忘的仪式（**0.107.1：本回合先消耗过才给 3 能**）、灰烬打击（消耗堆每张 +3 伤）、战鼓（抽 2，被消耗时 +2 能）、彼岸咆哮（AOE，回合末在消耗堆则自动打出）。
- **关键遗物**：卡戎之灰（每次消耗全体 3 伤）、金纸（每消耗 5 张抽 1）、燃烧木棍（每战首次消耗技能复制一张）、遗忘之魂（消耗随机 1 伤）。
- **缺点**：要凑 2 张能力牌才转；前期弱；腐化只能先古之民拿，别把整局押它。

## A · 力量流

- **思路**：前期便宜力量（燃烧/预备打击/与我一战！/主宰）+ 多段攻击（双重打击/飞剑回旋镖）；Boss 用恶魔形态长线成长；旋风斩/痛殴爆发群伤。
- **核心**：燃烧（1 费 +2/3 力）、恶魔形态（3 费，每回合 +2，测试版 +3）、双重打击（5×2）、旋风斩（X 费 5×X AOE）、飞剑回旋镖（3×3）。
- **辅助**：预备打击（7 伤+本回合 3 力）、与我一战！（5×2+3 力，敌人 +1 力）、主宰（易伤转力量）、烙印（0 费 -1 血 烧 1 张 +1 力）、痛殴（4×2，吞一张攻击加伤）。
- **缺点**：前期力量多为临时；恶魔形态 3 费；一直跳格挡会脆。

## A · 格挡 / 全身撞击流

- **思路**：叠不会消失的格挡，再用全身撞击/势不可当转伤害。
- **核心**：壁垒（格挡不消失）、全身撞击（伤害=当前格挡，敲完 0 费）、势不可当（2 费能力：每获得格挡对随机敌人 6 伤）。
- **辅助**：岿然不动（30/40 甲）、火焰屏障、耸肩、坚毅、重振精神。

## B · 易伤流 / 自伤流

- **易伤流**：让敌人长期易伤，再用放大/利用易伤的牌；易伤源（痛击/挑衅/上勾拳/战栗）+ 残酷（+25%）+ 欺凌（每层 +2）+ 主宰（转力量）。B 级原因：好用的易伤源少，凶恶过牌怕人工制品。
- **自伤流**：主动失血换力量/伤害/能量（放血/烙印/祭品/绯红披风/狱火）；缺“死割”类回复，战损难避免。

## 版本差异（0.107.1 正式版 vs 0.111 测试版）

- 被遗忘的仪式：0.107.1 **要先消耗过**才给 3 能；测试版去掉条件。
- 契约终结 AOE：0.107.1 **17**，测试版 18（本仓库 DB 记录为 18，可能来自测试版/旧数据，以游戏内文本为准）。
- 恶魔形态：0.107.1 每回合 +2，测试版 +3。
- 预备打击：0.107.1 临时 +2 力，测试版 +3。
- 主宰：0.107.1 罕见，测试版稀有。
- 跃跃欲试：0.107.1 是 2 费“手牌每张攻击给能量”；测试版是 3 费 15 甲+力量加成的防御牌。
- 彼岸咆哮：0.107.1 16 伤，测试版 18（DB 记 18）。
