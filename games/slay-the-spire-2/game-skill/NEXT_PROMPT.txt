战斗/操作硬规则（v22：结构化输入 + 结构化输出 + 5 条硬闸）：
- **5 条硬闸只有一处出处 `tools/hard_rules.py`**：`ctx.py` 每回合把 `rules` 注入局面包，
  照它执行即可；**不要在这份 prompt 或 SKILL 里另抄一套数字**（跑 `python tools/check_skill.py`
  和 `python tools/test_docs_consistency.py` 校验不漂移）。
- **每回合读局面包，再写牌序**（一回合 1 次请求）：
  `python tools/ctx.py` 只在进战斗/换界面/auto 停/拿不准时读一次；之后每回合直接用
  `python tools/act.py --file tmp_plan.json` 返回的 `ctx` 决策，**不要每回合再跑 ctx.py**。
  `ctx` 已含：手牌实费/全部效果、抽/弃/消耗堆、遗物、药水、双方 buff、
  每怪当前意图+下一次意图+机制、入伤/格挡/斩杀/击杀连锁、候选 `plans`。
- **`ctx.lessons`（按需出现的历史经验）**：只在敌人/血量/节点**真相关**时给 1–3 条，
  每条是「触发条件 → 建议动作」+ `s`=出处 run；它是账本核对过的失败案例，照做，
  但硬闸 `ctx.rules` 优先。没这个字段就是这回合没有相关经验，别硬套。
- **输出格式**：`{"say":["句1","句2"],"seq":[{"c":"BASH","t":0},{"c":"STRIKE_IRONCLAD","t":0},{"end":1}],"fx":{"e":1,"hp":59}}`
  - 牌序是「牌+药水」混排：`{"p":槽,"t":敌}`；`end` 必须在最后。
  - 需要看抽牌/Buff 落地就不写 `end`，只打半回合（回 `mid:1`），下一回合再续。
  - `fx` 可选；写了 `e/hp/take` 会被本地硬校验，错了解释器不执行、直接打回。
- **牌序按资源顺序**：0 费/回能/抽牌/变费 → 易伤/力量 → 高伤攻击 → 药水补费/补刀/保命 → end。
  无情猛攻后下一张攻击 0 费，把最大攻击放它后面；踩踏放最后；放血/祭品先打。
- **少请求**：杂怪（非精英/Boss、血安全）用
  `{"auto":{"turns":4,"stop_hp":30}}`，本地连打，一场普通战斗只花 1 次工具调用。
  精英/Boss/残血/需要抽牌才知道下一步的回合，逐回合 `ctx`+`act`。
- **见 `ok:false`**：一张都没打（或打一半 STOP）。用返回的 `ctx` 改 `seq` 重发，
  **绝不**自己补 `end_turn`；费用/目标/手牌变了都以返回的 `ctx` 为准。
  若返回 `receipt.ok=false`（`RECEIPT_LOST` / 退出码 4）= 接口收下了但状态没变（药水没喝/敌人没掉血），
  **别重发这一步**，先 `python tools/ctx.py` 看 `potions` 和敌人血量再决定。
- 药水：补能量在攻击前；斩杀药水最后补刀；格挡/回血在 `end` 前；targeted 写 `t`，漏了会 `invalid_target`。
- 杂怪先算「杀一只→另一只晕」：`ctx.calc.chain` 给了 kill/stun/save；杀带饥饿的怪的**同伴**才晕，杀它自己不会。
- 召唤者（爪牙）主人死则撤；2 回合内能杀本体就直杀，别先清小怪。
- incoming=0 时不要打纯防御（除非为 Body Slam/Barricade/Feel No Pain/保留格挡铺垫）。
- 结束回合前清 0 费牌（Spite/Anger/Bloodletting/Battle Trance 等），除非 Thorns/自伤致死。
- 只信稳定玩家回合：play_card/end_turn 不在 available_actions 就等，不在过渡态发 end_turn。
- HP<50% 下一格必须营火；商店先写“最缺/预算/必买/不买”，第二次进店没有目标就离开；不买便宜但不解决主要矛盾的牌。
- 篝火 HP≥70% 且有关键质变升级就锻造；不连敲两张打击/防御。
- Act1 目标：2 AOE、1–2 易伤、2–3 优质防御、1–2 运转、1 收尾，牌组≤15、最多 1 精英、Boss 前花光金币；Boss 前 **HP≥70% + 2 张 8+ 甲 + 药水先验过**（硬闸原文 `tools/hard_rules.py`）。
- 解说 banner 只写一句自然中文，不写“大肥鱼/DeepSeek/AI:”前缀，不拆 tag/黄字，整句同色；适度社区梗，不要每句都玩梗。
- 配音不必每刀配：进精英/Boss/低血时用
  `python tools/sts2.py quip "句1" "句2" "句3"` 一次埋 3–5 句（并行预热 TTS，页面排队播），
  台词从 `docs/IRONCLAD_VOICE.md` 挑（战士梗：燃烧之血/打击/痛击/自伤换血/营火）。
